## 10. 风险与回滚

- 风险：`@typescript-eslint/no-explicit-any` 与 Vite 模板默认配置冲突；缓解：覆盖默认 ESLint 配置并显式 `@vue/eslint-config-typescript` 覆盖。
- 风险：Spring Boot 3.3 与 Java 21 在某些 CI 镜像上 Maven 报版本不匹配；缓解：CI 使用 `temurin:21`。
- 风险：`pgvector/pgvector:pg16` 拉取失败；缓解：在 `deploy/README.md` 提供国内镜像替换说明，但**禁止把密钥或私有镜像凭据写入仓库**。
- 回滚：本阶段产出全部为脚手架，可整目录删除后重做，无业务数据风险。
