## Open Dataset Decision

Public computing-education datasets were checked before generating the final pack.

- CSSPLICE Dataset Catalog: many computing-education datasets, including Python tutoring, CodeWorkout, Blackbox, KC Modeling, FalconCode, and CS1QA.
- Google Research Python Runtime Errors: large Python runtime-error data derived from Project CodeNet.
- BlueJ Blackbox: relevant novice-programmer behavior data, but access is research-restricted and no new access is granted as of January 2026.
- Figshare Python/Bash submissions: large programming-submission data, but not Chinese tutoring dialogue.
- CodeWorkout/DataShop: useful programming-behavior data, but not Pythontopia-style Web workshop requests.

Decision: use these as taxonomy references, not as direct rows in the Pythontopia 5000-case pack. Direct mixing would blur course KC, evidence contracts, language style, and license/access boundaries.

## Risk Note

The partial smoke shows that full 5000 evaluation on the 8 GB laptop GPU may take many hours. The previous stable 1000-case beginner-noise run completed with concurrency 2, but the new 5000 pack has longer and more varied prompts. For reliability, start with concurrency 1, then only raise to 2 after the first 100-200 rows have stable latency and no refused connections.

## How to Interpret `1.000`

`1.000` in a tiny or truncated smoke is not proof of generalization. The full decision should use:

- by-slice metrics: new question, chapter slice, student expression, Web input
- by-noise-profile metrics
- by-chapter metrics
- by-agent metrics
- manual blind-review agreement
- comparison against the previous 1000-case raw/guarded baseline

Only if these slices remain strong should the result be described as robust rather than possible overfitting or benchmark weakness.
