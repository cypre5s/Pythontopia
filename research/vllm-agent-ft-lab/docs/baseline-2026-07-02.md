## What This Proves

- Local vLLM can serve Qwen3.5-4B on this laptop when using the AWQ 4-bit model.
- Real-time event logging and per-case metrics work.
- Multi-fold reporting and SVG chart generation work.
- The raw model is close on marker-level responses but not reliable enough for Agent protocol claims because JSON and evidence discipline are below target.

## What This Does Not Prove

- It does not prove a fine-tuned model improves the project yet.
- It does not prove generalization because the local set has only 10 cases.
- It does not prove end-to-end Pythontopia Agent integration because web/backend were intentionally untouched.
