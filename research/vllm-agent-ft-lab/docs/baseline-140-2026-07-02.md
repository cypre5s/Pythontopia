## Interpretation

This baseline is usable as the first research gate, but not yet as a story claim.

- The model is strong on marker-level content: most cases match the expected tutoring, planning, safety, or routing markers.
- The protocol gap is visible: JSON-valid output remains 60 percent, mainly because GuideCoach, MindMap, PathPlanner, and ResourceDesigner often answer with Markdown or prose rather than strict JSON.
- Grounding discipline remains below target at 64.29 percent. Some failures are real missing evidence/common-knowledge markers; some are scorer design pressure from agents where no evidence IDs are expected.
- Forbidden-answer leakage is 0 after the scorer fix, so the model is safe enough to proceed to candidate experiments, but this does not prove fine-tuning gains.

## Next Gate

The next candidate should target JSON protocol discipline and evidence/common-knowledge marking before optimizing broad content quality. A candidate only becomes story-worthy if it improves against this exact 140-case run with identical folds and also passes the story gate in `scripts/compare_experiments.py`.
