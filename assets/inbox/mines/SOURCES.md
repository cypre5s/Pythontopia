# Pythontopia / Bug 矿洞 (Mines) 素材来源

> 目录：`assets/inbox/mines/`
> 用途：Pythontopia 调试副本「Bug 矿洞」需要的 dungeon/mine tileset、火把光效、矿石、bug 怪物（NameError/TypeError/IndexError/KeyError/ValueError）。

本目录收录 4 套像素 dungeon/mine 素材，均允许在商业与教育项目中使用，2 套 CC0，1 套 CC0，1 套 CC-BY 3.0。所有素材保留原作者归属，使用时按本表的 license 字段执行 attribution。

---

## 1. Kenney — Tiny Dungeon

- **目录**：`mines/kenney_tiny-dungeon/`（symlink 至 `assets/inbox/kenney_tilesets/kenney_tiny-dungeon/`）
- **原始来源**：<https://kenney.nl/assets/tiny-dungeon>
- **作者**：Kenney Vleugels (Kenney NL)
- **License**：Creative Commons Zero (CC0 1.0 Universal) — Public Domain
- **License 链接**：<http://creativecommons.org/publicdomain/zero/1.0/>
- **Attribution**：可选；推荐写 "Tiles by Kenney (kenney.nl)"
- **格式**：16×16 px，132 块独立 tile + 1 张 12×11 拼合 tilemap.png / tilemap_packed.png
- **风格**：温暖木色 + 灰色石头 dungeon，含玩家/怪物/家具/陷阱
- **关键素材**：
  - 石头墙/地面 tiles
  - 木门 / 铁栅栏门
  - 楼梯（上 / 下）
  - 5 种敌人：绿史莱姆、棕老鼠、红小恶魔、红蝙蝠、棕蜘蛛
  - 紫色 hooded 幽灵、骷髅、僵尸
  - 火把 / 火盆 / 灯笼相关 tile
  - 宝箱、钥匙、卷轴、药水

## 2. Kenney — Roguelike Caves & Dungeons

- **目录**：`mines/kenney_roguelike-caves-dungeons/`（symlink 至 `assets/inbox/kenney_tilemaps/roguelike-caves-dungeons/`）
- **原始来源**：<https://kenney.nl/assets/roguelike-caves-dungeons>
- **作者**：Kenney Vleugels (Kenney NL)
- **License**：Creative Commons Zero (CC0 1.0 Universal) — Public Domain
- **License 链接**：<http://creativecommons.org/publicdomain/zero/1.0/>
- **Attribution**：可选；推荐写 "Tiles by Kenney (kenney.nl)"
- **格式**：16×16 px，单张大 spritesheet (`roguelikeDungeon_transparent.png` / `roguelikeDungeon_magenta.png`)
- **风格**：偏写实的灰色洞穴 + 棕色矿洞地形，含水域 / 蘑菇 / 骨头 / 矿石
- **关键素材**：
  - 灰色石头墙、棕色矿洞墙、灰色阶梯
  - 水池、毒池
  - 矿石点（金、银、铜外观的小块）
  - 骷髅头 / 骨头 / 蘑菇（病害装饰）
  - 蓝色 dungeon 房间 + 木栅栏门
  - 装饰柱子、刑具（用于复杂背景）

## 3. OpenGameArt — Dungeon Tileset (by Buch)

- **目录**：`mines/oga_buch_dungeon/`
- **原始来源**：<https://opengameart.org/content/dungeon-tileset>
- **作者**：Buch (<https://opengameart.org/users/buch>)
- **License**：Creative Commons Zero (CC0 1.0 Universal) — Public Domain
- **License 链接**：<http://creativecommons.org/publicdomain/zero/1.0/>
- **Attribution**：可选；推荐写 "Tiles by Buch (opengameart.org/users/buch)"
- **下载文件**：
  - `dungeon_pre.png`（完整 dungeon level 预览）
  - `dungeon_tiles_0.png` / `dungeon_tiles_2.png`（同一拼图的两个备份）
  - `tilesheet_1.png`（带 16×16 网格的拼图，便于切片）
- **格式**：16×16 px
- **风格**：深色石板地牢，氛围灰暗，带亮黄色火把，最贴合「Bug 矿洞」的阴森感
- **关键素材**：
  - 深灰石板地面 + 凹陷地面（楼梯井）
  - 厚石墙 / 拱门 / 入口
  - 上行 / 下行楼梯
  - 木门、铁门、栅栏门
  - **火把（带橙色火焰）** — 关键！
  - 蜡烛、蜡烛台
  - 小型角色：法师、骑士、僧侣（备用 player sprite）
  - 大型敌人：绿色史莱姆 / 黑色坩埚

## 4. OpenGameArt — Dungeon Tileset (by Calciumtrice)

- **目录**：`mines/oga_calciumtrice_dungeon/`
- **原始来源**：<https://opengameart.org/content/dungeon-tileset-1>
- **作者**：Calciumtrice (<https://twitter.com/Calciumtrice>, <https://calciumtrice.tumblr.com>)
- **License**：Creative Commons Attribution 3.0 (CC-BY 3.0)
- **License 链接**：<https://creativecommons.org/licenses/by/3.0/>
- **Attribution**：**必须**显示 "Dungeon tileset by Calciumtrice, CC-BY 3.0"（详见原作者要求）
- **下载文件**：
  - `dungeon_tileset_calciumtrice.png`（完整 tileset 索引图，含全部分类）
  - `dungeon_tileset_calciumtrice_simple.png`（简化版，不含复杂天花板）
  - `ceilings.png`（独立的天花板 tile）
  - `eggs0.png` / `eggs1.png` / `eggs2.png`（作者公开的示例场景截图）
  - `dungeon_tileset_calciumtrice.zip`（原始 zip，含 `instructions.txt`）
- **格式**：16×16 px（角色 / 怪物 16×32 px）
- **风格**：高对比灰色石头地牢，配色克制，氛围阴冷
- **关键素材**：
  - 天花板 / 墙体 / 地板（带边缘适配）
  - 门 / 栅栏（16×32, 16×48）
  - 墙面装饰：旗帜、武器架
  - 楼梯 / 地板装饰
  - 家具：椅子 / 桌子（16×32, 16×32, 16×48）
  - 容器：陶罐 / 木桶 / 麻袋
  - **火把（16×16）** — 关键！
  - **火焰特效（16×16 fire）** — 关键！
  - 拉杆 / 祭坛 / 卷轴 / 书本 / 药水 / 武器架
  - 战利品（金币 / 包裹）
  - 角色（16×32）
  - 小型怪物（16×16）：绿黏液 / 不同色 slime / 青蛙
  - 大型怪物（16×32）：骷髅 / 吸血鬼 / 兽人 / 巨魔
  - 阴影（multiply 图层）
  - 使用建议见 `oga_calciumtrice_dungeon/dungeon_tileset_calciumtrice.zip` 内的 `instructions.txt`
