## Validation

All 212 PNG files passed:

1. `file(1)` PNG magic-number check (89 50 4E 47 0D 0A 1A 0A) on the raw download set (3 fake PNGs in OPP2017 were detected as HTML 404 stubs and that whole pack was excluded from the inbox).
2. `Pillow Image.open() + Image.verify()` integrity check.
3. Dimension sanity check (each sheet's pixel size is a clean multiple of its documented cell size, confirming the frame layouts written in each `README_SOURCE.md`).

The 22 GIFs in `lpc_medieval_fantasy/` are documentation previews referenced by the upstream READMEs; they show which kit combinations look correct (e.g. `chain_armor_bandit.gif`, `robed_skeleton_spellcast.gif`, `dark_skinned_knight.gif`). They are **not** runtime assets but help integration agents pick valid layer combinations.

## What was deliberately NOT downloaded (and why)

See `SOURCES.md` § "排除清单" for the full list with reasons; in brief:

- LPC base assets / character bases / sage / gentleman / hakuna-matetee / in-battle-rpg-sprites: **CC-BY-SA-only** licences.
- `lpc-revised-character-basics`: **ZIP is 83.5 MB**, exceeds the single-source 30 MB cap.
- `24x32-characters-with-faces-big-pack`: already present at `assets/inbox/characters/cabbit_24x32/`.
- `animated-top-down-survivor-player`: educational tone mismatch (gun + zombie survivor).
- `opp2017-sprites-characters-objects-effects`: side-view platformer, fails the "俯视角 RPG" hard constraint.
