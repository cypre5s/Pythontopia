## Pythontopia / Pepper&Carrot compatibility

- Pepper&Carrot is a free / open-source webcomic universe; using its characters as Pythontopia NPCs is explicitly within the license but should be done **respectfully** — e.g. as cameo NPCs near the magic / library buildings, not as the main Python student.
- Do **not** modify the characters in ways that misrepresent the Pepper&Carrot universe (e.g. don't put Pepper in a Pythontopia school uniform that says "Pepper is the Pythontopia mascot"). They are guest NPCs.
