## Thumbnail / content description
Three RPG Maker VX/VX Ace formatted PNGs (TilesA2/A3/B) with LPC-style winter tiles: snow ground, pine trees (big + small editable variants), winter foliage. Designed to overlay on LPC Modified Base tiles.
