## Thumbnail / content description
Four 2048x2048 LPC-style terrain tilesets (spring/summer/autumn/winter) + a buildings tileset; preview shows a partial pixel city with house blocks, paths, trees, fences and seasonal grass color swaps. Compatible with the Tiled Map Editor, includes .tsx tileset configs and Terrain Sets.
