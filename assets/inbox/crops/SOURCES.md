## 2. 是否需要再下载补全（结论）

| 任务字段 | 结论 |
| --- | --- |
| 现有作物种类（70+）vs 65 KC 需求 | ✅ 超额（74 种 vs 65 KC） |
| 是否包含 ≥ 4 阶段成长动画 | ✅ LPC 与 fc16 均 5 阶段，fgb 4 阶段（前端可合成 withered 第 5 阶段） |
| 任务建议补全的 OpenGameArt 链接 | https://opengameart.org/content/farming-crops-16x16 ➜ **已存在**（Pack-B） |
| 同上 | https://opengameart.org/content/crop-sprites ➜ **不需要**，与 LPC + fc16 高度重复，仅 16x16 4 种 |
| **是否再次下载** | ❌ **不下载**。素材已够 65 KC + 备用 + 场景。 |

## 4. 下载校验（如需复现）

```bash
cd /home/cypress/Pythontopia/assets/inbox/crops
export HTTP_PROXY=http://127.0.0.1:7892
export HTTPS_PROXY=http://127.0.0.1:7892

# Pack-A
curl -L -o lpc-crops/crops-v2.1.zip \
  https://opengameart.org/sites/default/files/crops-v2.1.zip
unzip -o lpc-crops/crops-v2.1.zip -d lpc-crops/

# Pack-B
curl -L -o farming-crops-16x16/FarmingCrops16x16.zip \
  https://opengameart.org/sites/default/files/FarmingCrops16x16.zip
unzip -o farming-crops-16x16/FarmingCrops16x16.zip -d farming-crops-16x16/

# Pack-C
curl -L -o farming-game-basics/2DRP_CCArt_SimpleFarmGame.tar.gz \
  https://opengameart.org/sites/default/files/2DRP_CCArt_SimpleFarmGame.tar.gz
tar -xzf farming-game-basics/2DRP_CCArt_SimpleFarmGame.tar.gz -C farming-game-basics/

# Pack-D
curl -L -o lpc-farming-tilesets/submission_daneeklu.zip \
  https://opengameart.org/sites/default/files/submission_daneeklu.zip
unzip -o lpc-farming-tilesets/submission_daneeklu.zip -d lpc-farming-tilesets/
```
