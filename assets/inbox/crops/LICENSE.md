# Pythontopia 作物 / 植物生长精灵素材清单

本目录下的所有素材均来自 OpenGameArt.org，下载于 2026-05-21（UTC+8）。每个子目录是一个独立的素材包，请按下方的 license 要求逐包署名。商用 / 演示 / 比赛素材分发前必须保留本文件。

> Pythontopia 项目编号：crops/inbox
> 用途：作物生长阶段（种子 / 幼苗 / 发育 / 成熟 / 枯萎）映射到 Pythontopia 教育闭环（KC=种子、资源=施肥、练习=除草、Bug=矿洞病害、掌握度=作物成长、遗忘=枯萎）。

## 作物类型覆盖（验收用）

- **谷物**: 小麦（pack 2、pack 3）、水稻（pack 2）、玉米（pack 1、pack 2、pack 3）
- **块茎**: 马铃薯（pack 1、2、4）、红薯（pack 1）、木薯（pack 1、2）
- **根茎**: 胡萝卜（pack 1、4）、芜菁（pack 1、2）、洋葱 / 大蒜 / 韭葱（pack 1）
- **茄果**: 番茄（pack 1、2、3）、茄子（pack 1、2）、辣椒 / 灯笼椒（pack 1、4）
- **瓜类**: 西瓜 / 哈密瓜 / 蜜瓜（pack 1）、香瓜（pack 2）、南瓜 / 西葫芦（pack 1）
- **叶菜**: 圆白菜 / 紫甘蓝 / 白菜 / 西兰花 / 花椰菜 / 生菜 / 小白菜 / 芹菜 / 抱子甘蓝（pack 1）
- **豆类**: 豌豆 / 青豆（pack 1）、豆子（pack 4）
- **水果 / 浆果**: 草莓（pack 1、2）、蓝莓 / 黑莓 / 树莓（pack 1）、葡萄（pack 1、2）、菠萝（pack 1、2）、咖啡（pack 1、2）、橙子 / 柠檬 / 牛油果 / 猕猴桃（pack 1、2）
- **花 / 装饰**: 向日葵（pack 2）、玫瑰 / 郁金香（pack 2）、灌木 / 花卉瓦片（pack 4）
- **场景瓦片**: 翻耕土 / 田垄 / 围栏 / 长草 / 芦苇 / 草地 / 石头 / 小路（pack 3、pack 4）
