# Portal chevron source

`portal-chevron-up.png` is an unmodified copy of
`D:\godot-one\Icon\simple_arrow_up.png` (1024 × 1024), from the user-supplied
and user-confirmed purchased materials (2026-11-05).

This rendered white/light-blue chevron is separate from the 16-pixel SRW artwork.
Its local image metadata identifies a Blender icon scene but does not name an
author or license. No author or separate license was invented.

The original transparent PNG is displayed at 8 × 8 logical map pixels through
`shared/world/world.json` `portal_marker`. The renderer rotates it for each portal
direction. The source PNG was not edited, cropped or regenerated.
