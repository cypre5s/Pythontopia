# Pythontopia Web 发布包内容契约（allowlist + 违禁模式）
# ------------------------------------------------------------
# 本文件是 build_release_archive.sh（打包清理）与
# verify_release_archive.sh（包校验）共用的唯一内容契约。
# 改这里 = 同时改变打包排除规则与校验拒绝规则。
#
# 格式说明：
#   - 以 # 开头的整行是注释；空行忽略（不支持行内注释）。
#   - [toplevel] 段：发布包顶层必须“恰好”是这些条目，多一项
#     或少一项都判失败。目录以 / 结尾，文件不带 / 。
#   - [deny] 段：发布包内任何位置都不允许出现的模式。
#       * 不含斜杠的条目：按路径中任意一段（文件名或目录名）
#         做 shell glob 匹配，如 node_modules、*.pem、wechat-*。
#       * 含斜杠的条目：按发布包内相对路径做整段前缀匹配，
#         如 backend/data 匹配 backend/data 及其下所有内容。
# ============================================================
