# Pythontopia Docs

`docs/` 是 Pythontopia 的文档总目录。根目录只保留项目入口、构建脚本和 Web 全栈主链路；文档按用途归档在这里。

## 分类

| 目录 | 内容 |
| --- | --- |
| `architecture/` | 系统架构、字段映射、UI 规范、地图规范 |
| `clients/` | Web / Android / Windows / 微信共用契约与客户端说明 |
| `course-report/` | 课程/实训报告正文与生成稿 |
| `gameplay/` | 游戏化、NPC、进度、时钟等玩法设计 |
| `legal/` | 开源依赖、素材与合规边界说明 |
| `operations/` | 本地启动、执行状态、环境变量、运维记录 |
| `planning/`、`plan/`、`plans/` | 阶段规划、详细设计、历史实施计划 |
| `presentations/` | 演示脚本、PPT 大纲、比赛展示材料 |
| `product/` | 画像、掌握度、评价指标、主线产品说明 |
| `project/` | 变更日志、AI 协作披露、项目合规与工程记录 |
| `references/` | 外部格式参考与课程/实训模板资料 |
| `release/` | 发布说明、回归记录、版本交付材料 |
| `reports/` | 验收、评估、专项审计与阶段报告 |
| `testing/` | 测试计划、测试报告、可访问性与性能基线 |
| `../research/` | 隔离研究实验，当前包含 Qwen3.5/vLLM 微调与可靠性评测 |
