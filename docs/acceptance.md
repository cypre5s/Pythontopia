1. 从[已确认要求](requirements.md)确定影响范围，按[开发手册](development.md)执行相应检查。
2. 记录日期、源码提交或未提交工作区、实际环境、通过/失败/跳过、未覆盖项及真实证据位置；没有执行就写没有执行。

4. 纯文档修改只记录链接、归档完整性与一致性检查，不重新宣称功能验收通过。
