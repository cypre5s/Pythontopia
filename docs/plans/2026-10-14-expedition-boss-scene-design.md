# 无尽远征 Boss 战 Phaser 场景设计

## 目标

增强 Web 端无尽远征 Boss 节点的战斗反馈，同时让判题与学习内容继续留在可访问、可复制的 DOM 页面中。复用项目现有单一 Phaser.Game、Boss 立绘和已审计的 CC0 冲击音效，不引入新服务、游戏循环或虚构战斗数值。

## 方案

候选方案：

1. 在现有挑战 DOM 上添加动画与状态条：改动最小，但不符合用户选择的完整 Phaser 场景。
2. 在现有远征 Phaser 实例中切换地图/战斗展示：复用 Game 与场景入口，单一判题真源，符合约束，选用此方案。
3. 创建独立 Phaser.Game 或额外战斗应用：隔离度高，但违反单实例约束并增加生命周期复杂度，不采用。

在远征地图与 Boss 挑战共用的页面分支中保留一个 `ExpeditionCanvas`。地图时仍画远征塔；进入 Boss 节点时切换为 2D 战斗画面，使用项目已有的章节 Boss 立绘、程序绘制的竞技场地面与待机动效。代码编辑器、题目、判题结果、阶段说明和真实体力继续由 DOM 呈现。普通战斗节点不显示战斗画布。

场景状态直接来自 `useRogueRunStore`：Boss 名称/章节、当前阶段与总阶段、真实体力与上限、判题和结算状态。判题通过且服务端结算完成后才播放 Boss 受击动画与撞击音效；失败时等服务端结算更新体力，只显示实际剩余体力反馈，不对 Boss 伪造扣血。通过唯一 attempt key 去重动效，避免组件刷新重复播放。

复用 `assets/inbox/sfx_jump/kenney_impact-sounds/impactSoft_medium_000.ogg`，作为运行时音效登记至 Web 素材清单；原始许可证明为 Kenney Impact Sounds CC0。使用既有 `useAudio`，尊重全局静音/音量；支持 `prefers-reduced-motion`，关闭镜头震动与连续粒子时保留静态受击提示。战斗画布对辅助技术标记为装饰，阶段、结果和体力保留可读 DOM 文本。

## 验收

- 地图像素塔进入 Boss 挑战时复用同一 Phaser.Game，不新增 Game 实例；返回地图或离开页面可正确清理。
- Boss 节点显示适配桌面与窄屏的 Phaser 战斗场景，普通节点仍使用现有挑战页面。
- 成功判题并完成后端结算时播放 Boss 受击反馈；失败只反馈真实结算体力；判题或结算失败不会播放成功命中特效。
- Phaser 场景逻辑有针对结果去重/真源边界的单测，远征页面有节点级集成覆盖。
- 前端类型检查、相关测试与生产构建通过。

## 研究与素材

- Phaser 3 场景动画使用项目已安装的 Phaser 3.87 API；镜头效果前先按当前安装版本类型核对。
- Kenney 的 Impact Sounds 官方页面标注 CC0：https://kenney.nl/assets/impact-sounds 。
- DeepSeek 的视觉输入不属于本设计范围。
