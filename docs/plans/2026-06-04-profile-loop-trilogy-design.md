# 设计文档：画像闭环三连（玩中建画像 → 助教因材施教 → 情绪化小镇）

- 日期：2026-06-04
- 状态：方向已与用户确认（四方讨论收敛），待逐节细化后转实现计划
- 关联比赛：第十五届中国软件杯 A3「基于大模型的个性化资源生成与学习多智能体系统开发」（出题企业：科大讯飞）
- 关联代码：`learner/profile`（8 维画像）、`tutor`（看图答疑 + 助教小队 TutorCrew）、`services/pythontopia-graph`（LangGraph 多智能体）、`media`（讯飞多模态）

## 1. 背景与目标

A3 赛题要求：①对话式动态学习画像（≥6 维、随学随新、摒弃表单）②多智能体协同生成 ≥5 类资源 ③个性化路径规划与推送 ④多模态智能辅导（加分）⑤学习效果评估（加分）。评分：**创新价值与实用性 35% / 功能实现及技术要求 45% / 文档 10% / 演示视频·PPT 10%**，初赛含 7 分钟演示视频；AI 辅助工具须用科大讯飞相关工具。

差异化判断：赛题宽泛，多数队伍会交「套壳聊天 LMS」。Pythontopia 的**像素学习小镇**形态是创新分（35%）的核心抓手——但**只有当游戏机制可见地服务「因材施教」时才得分**，否则会被判华而不实而损功能分（45%）。本设计把游戏形态与画像深度绑定，形成可演示、可降级、对齐讯飞多模态的「画像闭环」。

## 2. 现状与缺口

8 维画像（`learner_profile.dimensions` JSONB，每维 `{score, evidence_count, tags[], metadata, last_updated}`）：专业背景 / 知识基础 / 学习目标 / 认知风格 / 学习偏好 / 易错模式 / 实践能力 / 情绪与坚持。来源：ProfileAgent 多轮访谈 + 学习事件被动更新（`PassiveProfileRevisionListener` → `PassiveProfileService`）+ 4 主观维自评 + `profile_revision` 审计 + 雷达图。

已发现缺口：
1. **仅 4 维真正被动吸数据**：practical_ability / error_pattern / knowledge_base / learning_preference。
2. **`cognitive_style` 是死的**：既不可自评也无被动信号，只在访谈时设一次 —— 违背赛题「随学随新」与 AGENTS.md「不得只根据一次问卷做静态推荐」。
3. **`emotion_persistence` 无行为信号**（监听器自身 TODO 注明班级任务→情绪维未接）。
4. **消费极浅**：8 维里实际只有 learning_preference 影响推荐媒介排序，其余只画雷达图。
5. **新功能不回流**：看图答疑 / 导师问答不写画像。

## 3. 设计原则

- **游戏服务因材施教**：每个游戏化元素必须在「30 秒内、屏幕上」体现"画像改变了教学/资源"，否则砍。
- **画像闭环**：建（采信号）→ 用（驱动体验）→ 反馈（回写并回测），形成动态画像。
- **防幻觉延伸到画像**：不因单次行为给学生贴死标签；展示证据/置信；提供学生纠偏阀。
- **可降级**：无网 / 无 key / 冷启动均不翻车（沿用现有占位降级 + 预置画像）。
- **多智能体可见化**：把抽象的「多智能体协同」做成屏幕上会说话的助教 NPC。

## 4. 总体方案：画像闭环三连

### 4.1 建 —— 玩中建画像（方向③）
在小镇内布置 2–3 个**低风险探针事件**（世界内选择，非弹窗问卷），从选择行为推断维度：
- 认知风格探针：如「先看图解 vs 先读代码 vs 先跑一个最小例子」→ `cognitive_style`（visual / verbal-logical / trial-and-error）。
- 情绪与坚持探针：失败后「再试一次 / 看提示 / 跳过」→ `emotion_persistence` 行为信号。
- 偏好探针：可复用既有多模态消费 tag。
约束：**选项美术等价中性、无优劣暗示**；可跳过；每次只写小增量 + `evidence_count`，多次累积才稳。命中赛题「对话式动态画像、摒弃表单、随学随新」硬指标，修缺口 2/3。

### 4.2 用 —— 助教小队因材施教（方向①）
将已落地的 `TutorCrew`（助教小队）从"可见流水线"升级为"个性化教学"：
- 导师阿派按 `cognitive_style` 换讲法（视觉型先甩图解/mermaid、逻辑型先给推理链、试错型先给最小可跑例）。
- 校对小核/识图员按 `error_pattern` tags 预警学生老坑。
- **回写**：学生实际采纳/停留于哪种讲法 → 被动回测 `cognitive_style`（闭环，修缺口 2/5）。
这是功能分（45%）、多模态与「多智能体协同」考点的主展示面。

### 4.3 境 —— 情绪化小镇（方向②）
小镇天气 / 时段 / NPC 心情随 `emotion_persistence` 连击**氛围级**变化：连挫 N 次 → 黄昏细雨 + 助教主动递台阶；连胜 → 晴天 / 节日。行为信号（重试 / 放弃 / 停留 / 逆袭）被动喂情绪维（修缺口 3）。**透明可纠偏、背景级不打扰、多信号触发**。这是 7 分钟视频的创新（35%）高光。

### 4.4 二期 —— 自适应脚手架（方向④）
训练场 / 代码实验室的难度、提示粒度、是否给可跑骨架由 `practical_ability + error_pattern + emotion_persistence` 实时决定（NPC 递"提示卷轴"道具），并回灌。复用同一套画像信号，MVP 后置。

## 5. 数据模型与画像信号

- 沿用 `learner_profile.dimensions` JSONB + `PassiveProfileService.applyDimensionUpdate`（已支持 score clamp、evidence_count、tags、metadata、revision 审计）。
- 新增被动信号（事件 → 维度 → 证据）：
  - 探针选择事件 → cognitive_style / emotion_persistence（新事件类型 + 监听）。
  - 助教讲法采纳事件 → cognitive_style 回测。
  - 失败重试/放弃/逆袭 → emotion_persistence。
- **新增 decay**（随时间轻微回归），避免早期信号永久定型，强化"随学随新"。
- **cognitive_style 纳入可纠偏**：允许学生在画像屋纠正（防幻觉/不贴死标签），需评估是否纳入 `SELF_EDITABLE_DIMENSIONS` 或单独纠偏接口。

## 6. 多智能体架构表达（赛题硬考点）

- NPC ↔ Agent 映射：助教小队各 NPC = 真 LangGraph 智能体（ProfileAgent / ResourceDesigner / Practice / Debug / GroundingCritic / Safety / Tutor）。
- 增设「调度 PM 助教」呈现任务拆解→分派→汇总（呼应 Marvis 主 Agent），把"多智能体协同"可视化。
- 复用现有 SSE `trace` 事件驱动 TutorCrew 拟人化状态；资源生成 / 看图答疑均挂名到对应助教。

## 7. UI / 交互

- 探针：世界内对话/选择卡，中性美术，可跳过。
- 助教讲法分支：同一答疑按 cognitive_style 改变首屏呈现（图解优先 / 推理链优先 / 最小例子优先），卡片化 + 流式（满足非功能要求）。
- 情绪化小镇：Phaser tint / 天气粒子（背景级）+ 助教主动台阶；提供"关闭情绪氛围"与纠偏入口。
- 画像屋：雷达图 + 证据/置信 + 纠偏阀。

## 8. 防幻觉 / 安全 / 伦理

- 画像断言附证据数与置信，不因单次行为贴标签；情绪推断透明、可关闭、可纠偏。
- 沿用 grounding + safety；探针/助教不输出可直接抄交的完整答案。

## 9. 降级与演示

- 预置一个"已有画像"的演示账号，保证个性化即时可见（规避冷启动空屏）。
- 无 key / 无网：多模态走占位降级、文本可切 dryrun；情绪/探针为本地逻辑不依赖外网。
- 7 分钟脚本：访谈/探针建画像 → 助教因材施教（视觉型 demo）→ 连挫触发情绪化小镇高光 → 资源生成/路径推送 → 评估回看。

## 10. 评分映射

- 创新 35%：情绪化小镇 + 玩中建画像 + 助教拟人多智能体（游戏化 × 个性化，区别于聊天 LMS）。
- 功能 45%：动态画像、≥5 类资源、路径推送、多模态答疑、评估闭环全部可见可跑。
- 文档 10%：本设计文档 + 系统/测试说明书 + 架构图。
- 演示 10%：上面的 7 分钟脚本 + 卡片化/流式 UI。

## 11. 风险与规避

- 华而不实 → 30 秒铁律 + 每个游戏元素绑定可见的画像→教学变化。
- 伪个性化/误判 → 多信号 + evidence_count + decay + 学生纠偏 + 透明置信。
- 演示翻车 → 预置画像 + 全面降级 + 提前录制兜底。
- 工作量超期 → MVP 先 ①，再 ③、②，④ 二期。

## 12. 里程碑 / MVP 顺序

1. **①助教因材施教**（壳已在）：cognitive_style 讲法分支 + 采纳回写 + 可见 agent trace。
2. **③玩中建画像**：2–3 探针 + 维度回写（复用 PassiveProfileService）。
3. **②情绪化小镇**：氛围级天气/心情 + 情绪行为信号。
4. **④自适应脚手架**：二期。

## 附：四方讨论纪要（评委 / 学习科学 / 游戏化 / 技术）

- 评委：三连通吃创新+功能，但每步须屏幕可见"画像改了教学"。
- 学习科学：先用③做实动态画像，①回测认知风格，②须透明可纠偏、勿过度推断。
- 游戏化：②是记忆点、①高 ROI、③做成世界内选择；花活 30 秒内服务教学。
- 技术：以"助教小队=可见多智能体"为主轴，全部复用 LangGraph+SSE+Phaser，预置画像+降级保演示。
