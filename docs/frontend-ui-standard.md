# Pythontopia 前端统一标准（新手友好）

> 目标：让高校 Python **初学者**零门槛上手——降低认知负荷、视觉一致、一屏一主任务。
> 适用：`frontend/`（Vue 3 + TS strict）。Android 端不在此文范围。

本标准基于主流教育/编程启蒙产品（Duolingo、Khan、NN/g、IxDF 2026）的通用法则落地到本项目的星露谷牛皮纸像素风。

---

## 1. 六条核心原则

1. **渐进披露**：一屏只放**一个主任务 / 一个主操作**；进阶项、次要信息收进折叠（accordion）、菜单或弹窗，用户需要时再展开。
2. **视觉层级**：主操作用大小/颜色/对比突出（主按钮）；次要操作靠边、弱化。一屏内**最多一个**实心主按钮。
3. **一致性**：按钮、面板、页头、空/载/错三态**一律用共享组件**，不要每页自造样式。
4. **分块**：长内容拆成可展开模块/步骤；长列表折叠或分页，默认不超过一屏。
5. **去重复 + 情境帮助**：不要两个控件干同一件事（如同时有返回箭头和 ✕）；用 tooltip / 引导空态代替长教程。
6. **可读性 + 无障碍**：学习正文用易读体；键盘可达；状态不只靠颜色（配文字/图标）。

---

## 2. 设计令牌（唯一来源）

- 唯一来源：`frontend/src/styles/tokens.css`。**禁止**在组件里散落十六进制色值（如 `#f7d774`/`#8c6a23`）。
- 颜色：`--pyt-color-*`（牛皮纸基色 + 语义 success/warning/danger/info + 强调 gold/accent）。
- 间距：`--pyt-space-1..6`（4 的倍数）。圆角：`--pyt-radius-sm/md/lg`（2/4/6，像素紧致）。
- 阴影：`--pyt-shadow-card/modal`。层级：`--pyt-z-hud/popover/overlay/modal/toast`（禁魔法数字）。
- 动效：`--pyt-motion-fast/base/slow`。焦点环：`--pyt-focus-ring`。

### 字体分层（重要）

| 场景 | 令牌 | 说明 |
|---|---|---|
| 游戏 UI / 按钮 / 徽章 / 标签 / 标题 | `--pyt-font-pixel` | 像素风，营造星露谷氛围 |
| **学习正文**（讲义、答疑、大段中文、题面解析） | `--pyt-font-read` | 易读无衬线，保证长文本可读性 |
| 代码 | `--pyt-font-mono` | 等宽 |

> 规则：凡是"给学生阅读理解"的连续文字，用 `--pyt-font-read`；凡是"游戏外壳/控件"，用 `--pyt-font-pixel`。`MarkdownView` 已默认 `--pyt-font-read`。

## 3. 核心共享组件（`frontend/src/components/ui/`）

| 组件 | 何时用 |
|---|---|
| `PyPage` | 内容页外壳：标准页头（返回 + 标题 + 右侧 actions 槽）+ 滚动内容区。配 `AppLayout` 使用 |
| `PyPanel` | 牛皮纸 9-slice 面板容器，统一描边/底色/内边距 |
| `PyButton` | 所有按钮：`variant=primary/secondary/ghost`、`size=sm/md`、`block`。一屏只一个 primary |
| `PyEmptyState` | 空状态：主文案 + 副文案 + "下一步"动作槽（已存在） |
| `PySkeleton` | 加载占位（已存在） |
| `PyError` | 错误态：原因 + 重试动作 |

**三态约定**：异步区域必须覆盖 加载（PySkeleton）/ 空（PyEmptyState）/ 错（PyError）三态，不要白屏或只 alert。

---

## 4. 渐进披露落地规则

- 一屏一主操作；其余动作放 `…更多` 菜单或折叠区。
- 配置类页面：默认只露最常用项，进阶选项折叠在「高级」里。
- 长列表：默认折叠/分页，给「展开全部」。
- 游戏内 HUD：默认极简（小地图 + 当前任务 + 一个菜单入口），其余浮层进菜单。

---

## 5. 文案与 KC 显示

- 纯口语中文，术语首次出现给一句解释。
- **学生侧一律显示知识点中文名**（`@/data/kcNames` 的 `kcDisplayName(code)`），**不得**直接暴露 `PY43-KC-*` 原始编码。
- 空/错文案给"下一步"指引（"还没有 X，去 Y 试试"）。

- [ ] 无散落 hex 色值，全部走 `--pyt-*` 令牌
- [ ] 按钮/面板/页头用共享组件，未自造

- [ ] 异步区覆盖 加载/空/错 三态

## 7. 路线图（按新手影响优先级）

1. **地基**：本标准 + `--pyt-font-read` + 核心壳组件（PyPage/PyPanel/PyButton/PyError）。✅ 进行中
2. **游戏内 HUD 精简**：15 浮层 → 极简默认 + 一个菜单。
3. **统一壳套用**：高频页（百晓工坊 / 图书馆 / 讲解 / 训练）改用共享壳 + 渐进披露。
4. **KC 编码收敛**：学生侧全覆盖 `kcDisplayName`。
5. **新手引导**：登录/首页/首次进入的轻量引导（不打断、可跳过）。
