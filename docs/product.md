# Pythontopia Reborn 产品范围

学生登录后在原像素小镇行走，通过人物、地点和脚本任务进入学习。章节组织内容，任务组织体验。教师使用普通后台管理班级、资源、任务和发布时间。首版只有 Web，不保留旧画像、自动路径、工坊生成平台、矿洞副本、Boss、经济和原生客户端。

世界不随打开课程而销毁。同一时刻只有一个主要工作区：教学、练习、日志、学习资料、地图、班级或设置；切换替换当前工作区。输入代码时不移动角色，退出账号清除会话状态。课件长文与代码使用可读字体。阅读记录表示参与，正式练习才形成成绩。

小镇11栋房屋上方只显示中文名称，屋顶名称和楼体可点击导航；入口使用小型素材箭头。底部“学习资料”和“我的班级”之间的“地图”打开当前地图：左侧放大预览、右侧独立目标卡，右卡顶部用图标筛选全部/建筑/人物；外层透明无大底板，沿用任务日志的深绿、纸面与暖金配色。玩家以青蓝描边标记和“你在这里”显示，不受筛选影响；打开地图读取角色即时位置，窄屏自动将画布滚到玩家附近。没有地图选择，小镇预览只包含实际50×40地图，不纳入外围景观。选择目标不移动角色，点击前往后才导航；地图不接管WASD或方向键选择，关闭后焦点回到世界。门、落点、开放条件和建筑锚点来自同一地图配置，普通位置保存不允许绕过门跨图。

图书馆使用素材地板、墙面、10组满书书架、两张完整宽阅读桌和四张独立短木凳搭建，桌脚与座位留有间距，中央通道和服务台清楚，角色在小地图内保持居中。所有书架都能点击或靠近阅读，统一称为图书馆书架，不局限于西侧一点。互动提示随角色位置实时更新，短文字与背景等宽；未开放房屋没有E提示或未开放弹字。室外景观可延伸到行走范围外；景观、镜头范围与可行走范围分别配置，外侧景观不能行走，当前地图预览不显示这些外景。

界面遵循game-ui-design与game-ui-ux的层级、渐进展示和输入所有权原则：小镇底部菜单保留任务日志、学习资料、班级与设置；委托卡显示服务端步骤、当前目标及学习/练习入口，可以收起。自动追踪会越过已完成委托，未选择分支和可选节点不混入必做步骤分母。对话或工作区打开时隐藏HUD并暂停移动。

详情导航保留有界返回路径，始终只显示当前一个工作区。Esc返回一级；没有上一级时回到小镇。右上角“回到小镇”直接关闭工作区。对话支持键盘焦点、Tab循环和Esc离开，迟到的请求不得重新打开已离开的界面。设置提供100%–200%文字大小、减少界面动效和环境音乐；设备的减少动态效果偏好始终生效。文字偏好属于当前设备，不代表学习进度。

学习区以正文、实际资料版本/页码和当前题目为主，窄屏在内容与助教间切换，隐藏区域不接收焦点。文本/PDF/视频阅读位置按用户、班级、材料版本分开保存；图书馆可返回原列表位置。未作答的概念题不能正式提交，服务端仍负责判定与结算。

第一章版本1通过镇长来信、计算思维课程、东侧练习场与返回汇报，点亮小镇并开放图书馆。第二章拜访林教授，选择语言概念或输入输出编程路线，再完成馆员和书架的并列目标。未选择的支路不影响通关。剧情为原创，教学来自课程包 43。新增概念题明确标注人工编写与出处。

第一章版本2使用章节脚本串联完整旅程：镇长欢迎后开放图书馆，馆员引导指定阅读并以助教身份回答主动问题；退出时告别，重返可选择续读。完成指定阅读后去东侧教练处练习，再回镇长处进行独立章节测试并听取总结。NPC按个人进度选择首访、提醒、续读或完成后的对白；阅读位置保存在服务端。原版本1及旧存档保留，发布版本2供新学生体验。指定阅读形成参与记录，练习和测试形成独立成绩；测试不开放助教。

助教只在学习工作区主动发消息时运行。普通对白、移动、阅读翻页、任务判定、播放视频和日志不调用模型。没有模型配置时明确显示不可用。正式编程判题依赖外部隔离 Judge0；其不可用不等于学生答错，也不阻止概念题和世界使用。

原课件媒体未包含在仓库中。现有内容是实际提取的文本页，不伪装成完整 PPT/PDF；视频清单也不代表在线播放完成。教师可上传合法自有文本、PDF、PPT/PPTX、MP4/WebM，处理成功后绑定活动。
