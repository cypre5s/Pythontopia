# Pythontopia Reborn 产品范围

学生登录后在原像素小镇行走，通过人物、地点和脚本任务进入学习。章节组织内容，任务组织体验。教师使用普通后台管理班级、资源、任务和发布时间。首版只有 Web，不保留旧画像、自动路径、工坊生成平台、矿洞副本、Boss、经济和原生客户端。

世界不随打开课程而销毁。同一时刻只有一个主要工作区：教学、练习、日志、图书馆、班级或设置；切换替换当前工作区。输入代码时不移动角色，退出账号清除会话状态。课件长文与代码使用可读字体。阅读记录表示参与，正式练习才形成成绩。

界面遵循game-ui-design与game-ui-ux的层级、渐进展示和输入所有权原则：小镇底部菜单保留任务日志、学习资料、班级与设置；委托卡显示服务端步骤、当前目标及学习/练习入口，可以收起。自动追踪会越过已完成委托，未选择分支和可选节点不混入必做步骤分母。对话或工作区打开时隐藏HUD并暂停移动。

详情导航保留有界返回路径，始终只显示当前一个工作区。Esc返回一级；没有上一级时回到小镇。右上角“回到小镇”直接关闭工作区。对话支持键盘焦点、Tab循环和Esc离开，迟到的请求不得重新打开已离开的界面。设置提供100%–200%文字大小、减少界面动效和环境音乐；设备的减少动态效果偏好始终生效。文字偏好属于当前设备，不代表学习进度。

学习区以正文、实际资料版本/页码和当前题目为主，窄屏在内容与助教间切换，隐藏区域不接收焦点。文本/PDF/视频阅读位置按用户、班级、材料版本分开保存；图书馆可返回原列表位置。未作答的概念题不能正式提交，服务端仍负责判定与结算。

第一章通过镇长来信、计算思维课程、东侧练习场与返回汇报，点亮小镇并开放图书馆。第二章拜访林教授，选择语言概念或输入输出编程路线，再完成馆员和书架的并列目标。未选择的支路不影响通关。剧情为原创，教学来自课程包 43。新增概念题明确标注人工编写与出处。

助教只在学习工作区主动发消息时运行。普通对白、移动、阅读翻页、任务判定、播放视频和日志不调用模型。没有模型配置时明确显示不可用。正式编程判题依赖外部隔离 Judge0；其不可用不等于学生答错，也不阻止概念题和世界使用。

原课件媒体未包含在仓库中。现有内容是实际提取的文本页，不伪装成完整 PPT/PDF；视频清单也不代表在线播放完成。教师可上传合法自有文本、PDF、PPT/PPTX、MP4/WebM，处理成功后绑定活动。

教师管理界面按班级教学、课程资源、学习体验分组。学习记录以班级总人数、成员列表和真实已完成章节数为主，不展示任务事件/提交统计卡和状态分布。章节管理列出每章解锁日期，支持定时或立即解锁，已有内容版本与前置条件保留在内部；老师不填写任务版本。课程与知识点分为两个子标签，各自分页；新建编辑使用弹窗，材料上传与题目新建同样使用弹窗，列表默认每页10条，可选20/50条。题目基本字段使用普通表单，高级配置保留真实来源、私有用例及完整JSON。活动、NPC与任务配置保持现状，等待学生端方案确定后再改。


后台页面采用单一主标题，无分类眉题和页面介绍。列表的搜索/筛选/主要操作位于表格外；表格面板只保留数据、空状态与分页。课程子标签已表达分类，不再重复显示面板标题或介绍。时区、错误、授权限制等操作必需信息仍保留。
