# Pythontopia Reborn 产品范围

学生登录后在原像素小镇行走，通过人物、地点和脚本任务进入学习。章节组织内容，任务组织体验。教师使用普通后台管理班级、资源、任务和发布时间。首版只有 Web，不保留旧画像、自动路径、工坊生成平台、矿洞副本、Boss、经济和原生客户端。

世界不随打开课程而销毁。同一时刻只有一个主要工作区：教学、练习、日志、学习资料、地图、班级或设置；切换替换当前工作区。输入代码时不移动角色，退出账号清除会话状态。课件长文与代码使用可读字体。阅读记录表示参与，正式练习才形成成绩。

任务日志、小镇图书馆、小镇地图、我的班级、设置、资料阅读与练习使用统一的近满屏工作区：左上金线图标与单一中文主标题，右上深绿圆角“回到小镇”，有历史时另提供返回一级。外壳透明，暖纸内容与目录分别形成独立卡片，间隙露出小镇，颜色沿用任务日志的深绿与暖金。正文独立滚动，基础表单控件、滚动条、选中和焦点样式共用。完整设计与后台边界见[设计规范](design/README.md)。

“小镇图书馆”按章节组织已授权材料，侧边提供章节目录，顶部提供名称/章节搜索和全部、课件、视频筛选。只有实际可访问的资料进入目录，不因搜索或筛选开放其他章节。进入PDF或视频再返回时，保留当前用户、班级的搜索词、类型、章节选择和列表位置，阅读页码与视频播放位置继续按原材料保存。

“我的班级”先展示当前班级、授课教师、本人学习情况和当前主线目标。步骤进度排除可选目标与未选择分支，表示任务完成情况，不冒充知识掌握率。侧边另有切换班级与加入班级：成功载入目标班级后再整体切换，失败保留原班级与存档；加入新班级后刷新列表，由学生显式选择是否切换，已有班级记录保留。

设置以账户为默认分类，侧边依次为账户、界面、音乐、操作、关于。设置项使用统一的行布局、开关、选择框和音量滑块；音乐音量直接控制当前小镇环境音乐。字号、减少动效和音量保存在本机，遵循设备减少动态效果偏好。设置不再承担跳转班级或学习资料的导航职责；素材许可与课程来源直接放在“关于”中，完整来源页仍可独立访问。账户页显示当前身份与退出入口，教师身份保留教师工作台入口。

小镇11栋房屋上方只显示中文名称，屋顶名称和楼体可点击导航；入口使用小型素材箭头。底部“学习资料”和“我的班级”之间的“地图”打开当前地图：左侧放大预览、右侧独立目标卡，右卡顶部用图标筛选全部/建筑/人物；外层透明无大底板，沿用任务日志的深绿、纸面与暖金配色。玩家以青蓝描边标记和“你在这里”显示，不受筛选影响；打开地图读取角色即时位置，窄屏自动将画布滚到玩家附近。没有地图选择，小镇预览只包含实际50×40地图，不纳入外围景观。选择目标不移动角色，点击前往后才导航；地图不接管WASD或方向键选择，关闭后焦点回到世界。门、落点、开放条件和建筑锚点来自同一地图配置，普通位置保存不允许绕过门跨图。

图书馆使用素材地板、墙面、10组满书书架、两张完整宽阅读桌和四张独立短木凳搭建，桌脚与座位留有间距，中央通道和服务台清楚，角色在小地图内保持居中。所有书架都能点击或靠近阅读，统一称为图书馆书架，不局限于西侧一点。互动提示随角色位置实时更新，短文字与背景等宽；未开放房屋没有E提示或未开放弹字。室外景观可延伸到行走范围外；景观、镜头范围与可行走范围分别配置，外侧景观不能行走，当前地图预览不显示这些外景。

界面遵循game-ui-design与game-ui-ux的层级、渐进展示和输入所有权原则：小镇底部菜单保留任务日志、学习资料、班级与设置；委托卡显示服务端步骤、当前目标及学习/练习入口，可以收起。自动追踪会越过已完成委托，未选择分支和可选节点不混入必做步骤分母。对话或工作区打开时隐藏HUD并暂停移动。

详情导航保留有界返回路径，始终只显示当前一个工作区。Esc返回一级；没有上一级时回到小镇。右上角“回到小镇”直接关闭工作区。对话支持键盘焦点、Tab循环和Esc离开，迟到的请求不得重新打开已离开的界面。设置提供100%–200%文字大小、减少界面动效和环境音乐；设备的减少动态效果偏好始终生效。文字偏好属于当前设备，不代表学习进度。

学习区以正文、实际资料标题/页码和当前题目为主，窄屏在内容与助教间切换，隐藏区域不接收焦点。文本/PDF/视频阅读位置按用户、班级、材料ID分开保存；图书馆可返回原列表位置；旧材料缓存一次性迁移到当前材料ID，保留本机阅读位置。未作答的概念题不能正式提交，服务端仍负责判定与结算。

当前内置主线仅有“初来小镇：第一堂 Python 课”（arrival）。其他旧委托与第二章分支教学流程已退出当前任务配置和学生任务列表；七章课程、知识点和材料仍作为教学资源保留，开放其他章节不会自动产生旧任务。剧情为原创，教学来自课程包43，新增概念题明确标注人工编写与出处。

第一章使用章节脚本串联完整旅程：镇长欢迎后开放图书馆，馆员引导指定阅读并以助教身份回答主动问题；退出时告别，重返可选择续读。完成指定阅读后去东侧教练处练习，再回镇长处进行独立章节测试并听取总结。NPC按个人进度选择首访、提醒、续读或完成后的对白；阅读位置保存在服务端。教学配置按稳定ID直接更新，所有学生读取当前内容；既有阅读、节点记录和成绩保留。指定阅读形成参与记录，练习和测试形成独立成绩；测试不开放助教。

助教只在学习工作区主动发消息时运行。普通对白、移动、阅读翻页、任务判定、播放视频和日志不调用模型。没有模型配置时明确显示不可用。正式编程判题依赖外部隔离 Judge0；其不可用不等于学生答错，也不阻止概念题和世界使用。

课程媒体采用私有存储：7份真实PDF替换原文本展示，原页面编号和提取文本保留；34段视频按章节进入资料库并标为补充视频，观看不影响任务和成绩。材料仍受班级/章节开放权限约束，原PPT/PPTX没有提供，媒体不进入前端公共目录或Git。教师可上传合法自有文本、PDF、PPT/PPTX、MP4/WebM，处理成功后绑定活动。

教师管理界面按班级教学、课程资源、学习体验分组。学习记录以班级总人数、成员列表和真实已完成章节数为主，不展示任务事件/提交统计卡和状态分布。章节管理列出每章解锁日期，支持定时或立即解锁，保留前置条件；不维护内容版本。课程与知识点分为两个子标签，各自分页；新建编辑使用弹窗，材料上传与题目新建同样使用弹窗，列表默认每页10条，可选20/50条。题目基本字段使用普通表单，高级配置保留真实来源、私有用例及完整JSON。教师可继续编写自有活动与任务；系统不再预置其他旧主线。


后台页面采用单一主标题，无分类眉题和页面介绍。列表的搜索/筛选/主要操作位于表格外；表格面板只保留数据、空状态与分页。课程子标签已表达分类，不再重复显示面板标题或介绍。时区、错误、授权限制等操作必需信息仍保留。

## 浏览器支持范围（2026-11-05更新）
当前交付与CI验收以1920×1080桌面Chromium浏览器、键盘鼠标操作为准。手机横竖屏、触屏、小屏和超宽屏不作为通过条件；已有响应式样式保留，但不声明这些设备已通过验收。
