# Pythontopia Reborn 产品范围

学生登录后在原像素小镇行走，通过人物、地点和脚本任务进入学习。章节组织内容，任务组织体验。教师使用普通后台管理班级、资源、任务和发布时间。首版只有 Web，不保留旧画像、自动路径、工坊生成平台、矿洞副本、Boss、经济和原生客户端。

世界不随打开课程而销毁。同一时刻只有一个主要工作区：教学、练习、日志、图书馆、班级或设置；切换替换当前工作区。输入代码时不移动角色，退出账号清除会话状态。课件长文与代码使用可读字体。阅读记录表示参与，正式练习才形成成绩。

第一章通过镇长来信、计算思维课程、东侧练习场与返回汇报，点亮小镇并开放图书馆。第二章拜访林教授，选择语言概念或输入输出编程路线，再完成馆员和书架的并列目标。未选择的支路不影响通关。剧情为原创，教学来自课程包 43。新增概念题明确标注人工编写与出处。

助教只在学习工作区主动发消息时运行。普通对白、移动、阅读翻页、任务判定、播放视频和日志不调用模型。没有模型配置时明确显示不可用。正式编程判题依赖外部隔离 Judge0；其不可用不等于学生答错，也不阻止概念题和世界使用。

原课件媒体未包含在仓库中。现有内容是实际提取的文本页，不伪装成完整 PPT/PDF；视频清单也不代表在线播放完成。教师可上传合法自有文本、PDF、PPT/PPTX、MP4/WebM，处理成功后绑定活动。
