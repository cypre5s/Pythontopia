# demo_v1 视频剪辑说明

> 7 分钟演示视频 `demo_v1.mp4` 的剪辑时间轴、字幕清单与评审现场说明。视频本体不入 git，
> 制作时按本文件分段录制，再用 OBS Studio + 剪映/Premiere 合成。

## 1. 剪辑时间轴

| # | 时间段 | 内容 | 录制脚本对应章节 |
| --- | --- | --- | --- |
| 1 | 00:00 – 00:30 | 项目介绍 + 教育闭环图 | `demo_script.md` 第 1 节 |
| 2 | 00:30 – 01:30 | 学生登录 + 进入小镇 | 第 2 节 |
| 3 | 01:30 – 03:00 | 画像 + 知识田 + 资源工坊 | 第 3 节 |
| 4 | 03:00 – 04:30 | 训练场 + Bug 矿洞 | 第 4 节 |
| 5 | 04:30 – 05:30 | 教师班级看板 | 第 5 节 |
| 6 | 05:30 – 06:30 | 复盘大厅评估 + accept new path | 第 6 节 |
| 7 | 06:30 – 07:00 | 工程质量 + 总结 | 第 7 节 |

## 2. 字幕清单（中文 SRT）

字幕文件命名 `demo_v1.zh-CN.srt`，与 demo_v1.mp4 一并放入提交包。
每段字幕长度建议 ≤ 18 个汉字，避免遮挡 UI。

## 3. 录制工具

- 录屏：OBS Studio（开源）。
- 分辨率：1920×1080，30 fps，码率 6Mbps。
- 配音：项目成员真人配音，禁用未授权背景音乐。
- 演示账号：`demo-teacher-01` / `demo-stu-01`（演示前用 `seed_demo_classroom.sh` 注入，演示后清理）。

## 4. 视频后处理

- 开头 logo：项目首页截图 + 项目名水印。
- 章节切换：1 秒淡入淡出。
- 关键操作：放大鼠标光标 1.3 倍。
- 演示账号密码：录制前关掉浏览器自动填充提示。

## 5. 提交清单

- `demo_v1.mp4`（< 200MB）。
- `demo_v1.zh-CN.srt`。
- `images/cover.png`（视频封面，无 PII）。
- `images/scene_01.png` ~ `scene_07.png`（每段开头一张截图）。

视频与字幕只放在 `docs/release/`（不入 git）；提交包 zip 时一并打包。
