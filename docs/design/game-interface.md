# 游戏界面规范

## 范围与原则

本规范用于学生进入 `/world` 后的任务日志、小镇图书馆、小镇地图、我的班级、设置、资料阅读、课程、练习和单元测验工作区。Phaser 保留小镇与角色，Vue 展示可阅读、可输入的学习界面；同一时刻只有一个主要工作区。

工作区沿用任务日志的深绿、暖纸和金色，采用地图式的独立内容卡片：外壳完全透明，各卡片之间能看到小镇。页面信息以当前任务和内容为主，不添加装饰性副标题、重复大标题或无实际数据的统计卡。

世界 HUD、人物对话和登录入口仍保留各自用途，不为了外观统一而变成额外工作区。本规范不增加任务、学习能力、手柄交互或新的编辑器。

登录和注册入口使用“学号”标签与文本输入框，保留前导零，提供数字键盘提示和用户名自动填充；不使用数值输入框或邮箱校验。账户设置与开发工具展示学号。

账户设置提供当前密码、新密码与确认新密码表单，注册和自助改密均至少6位；显示提交中、错误和成功状态。教师创建或重置为学号密码的学生先进入独立改密页，完成后才能进入小镇；刷新或直接访问世界不能绕过服务端限制。现有学生密码不随升级改变。

## 布局

当前基准是 1920×1080 桌面 Chromium，使用键盘和鼠标。近满屏布局保留小镇边缘与卡片间隙。

| 项目 | 规则 |
| --- | --- |
| 水平外边距 | `clamp(20px, 2vw, 40px)`，1920px 宽时约 38.4px |
| 垂直外边距 | 顶部 24px、底部 28px，并尊重浏览器安全区；现有小尺寸布局分别为 14px、18px |
| 共享页头 | 基础高度 70px；字号增大时允许内容伸展，不能裁掉标题或返回按钮 |
| 标题图标 | 42×42px 金色线性图标 |
| 主标题 | `1.7rem` 中文标题，由共享页头输出 |
| 独立卡片间距 | 22px，间隙保持透明并露出小镇 |
| 卡片圆角 | 16px |
| 控件圆角 | 8px |
| 基础操作目标 | 至少 44×44px；窄小勾选图形可通过关联标签提供完整操作区 |
| 滚动条 | 8px，沿用共享颜色和悬停状态 |

`.workspace-shell` 不设置背景、边框或阴影。页面可以由目录卡片与正文卡片组成，也可以按地图、课程或练习内容拆分卡片；不得在这些卡片后再包整块不透明底板。卡片内部按阅读需要组织内容，不堆叠多层装饰边框。

目录和正文容器应设置可收缩尺寸与各自的滚动边界。长列表、纯文本正文、题目、助教消息和代码区按需要独立滚动；PDF 阅读左侧整体不产生滚动条，完整页面适应剩余宽高。标题、返回和必要操作保持可达。新增布局不得靠固定屏幕坐标放置正文或遮挡操作按钮。

## 学习工作区：内容与支持

阅读与练习共用“主内容 + 学习支持”结构。主内容占较宽一侧，学习支持占另一侧，卡片之间仍露出小镇。沿用深绿、暖纸和金色、16px 圆角与共享控件；参考聊天界面的留白和消息排版，不另外引入白底应用主题。页头仍只有 `OverlayHost.vue` 输出的“资料阅读”“练习”或“单元测验”。

### 资料阅读

PDF 与演示课件的左侧由一张完整阅读卡片和底部分页卡片组成。阅读卡片的全部可用空间用于当前页，按页面比例同时适应宽度和高度；不能只按宽度放大后依靠纵向滚动。切换页面、调节分栏、改变窗口或重新显示隐藏区域后，重新计算可用尺寸，保持原始页码及阅读位置。

底部分页条左侧为“上一页”、中央为资料题名与原始页码、右侧为“下一页”，并提供表示当前页位置的细进度条。阅读位置与服务端验证的阅读目标进度分开标注，不能把翻到末页称为完成阅读。长题名允许换行，不能把按钮推出卡片。资料题名只在必要位置显示，不再堆叠文件大标题、类型副标题和技术提示。加载、缺失文件或读取失败在阅读卡片内清楚说明，并保留导航入口。

学生页面不显示“转换文本”“提取文本”或相应展开区。原始 PDF、课件页面、视频和人工编写的文本资料仍按各自形式展示；检索与引用需要的后台文本继续保留，页面编号、阅读记录和完成判断不因此改变。阅读进度、指定页及完成操作集中在学习目标区域，避免挤占 PDF 阅读卡片。

视频和纯文本资料沿用相同的内容、支持与底部导航层级。视频保持原始比例与浏览器播放控件；长文本允许正文自身滚动，不能为满足固定高度而裁掉内容。练习的题目、答案、代码、运行结果及正式提交仍保留必要的内部滚动与真实判题反馈。

### 学习目标与角色助教

右侧使用“学习目标”、对应内容目录及实际角色名称标签页：阅读用“文档目录”，练习和测验用“题目目录”。目录用于定位内容，不能再在左侧正文上方重复一排题目按钮。阅读活动通常是“图书管理员”，练习使用当前活动绑定的角色；不要把所有角色改成同一个名字。默认先展示学习目标，切换标签只改变当前可见区域，不能清空草稿、会话或阅读位置。标签有明确选中状态、可见焦点与正确的标签页语义，隐藏内容不能接收键盘输入。

文档目录按原始页码列出每页的真实页标题，当前页有明确状态，点击直接跳页；不展示自动提取的正文。长目录在右侧独立滚动，不能挤压左侧PDF。学习目标按“阅读某份资料”“完成练习”等完整目标组织，每项附服务端进度条，并可包含指定页与题目明细。学习目标来自当前已授权的活动配置，例如指定原始页码、对应页标题、练习题目和服务端确认的完成状态。没有独立教学目标字段时，不能编造“已掌握知识”或新的解锁条件。图书馆直接打开已授权资料时仍提供图书管理员助教，以当前资料建立会话；没有活动时不伪造学习目标。资料未就绪或权限失效时禁止提问，没有模型配置时明确显示不可用。

助教区域采用简洁聊天排版：顶部显示角色名称，学生消息靠右形成浅色气泡，助教回复在消息区自然排版，长回复保持换行和清晰行距。引用提供可操作入口；真实不可用、未开放、错误、回复中和停止状态使用简短文字说明，避免多层问候、提示和装饰标题挤占对话。

使用当前活动角色已有的授权立绘作淡背景，不新增来源不明的角色图。立绘不拦截鼠标或键盘，不参与屏幕阅读器内容，不覆盖控件；其透明度与纸面遮罩必须保证文字清楚可读。即使图片加载失败，角色名称、消息和操作仍完整可用。

提问输入框固定在助教卡片底部，使用“向助教提问”作为输入提示并保留可访问标签；发送采用圆形向上箭头图标，仍有“发送”的可访问名称，停止操作始终可达。正常输入不常驻展示字数计数；超过2000字时保留完整原文，显示清晰错误并阻止发送，不得静默截断。消息历史单独滚动，输入框不随长对话移出视口。仅学生明确发送问题才调用助教；切换标签、查看目标、载入立绘、翻页和调节布局不产生模型调用。

`content.learning` 可配置整份课件、指定页范围、最少有效视频播放时间和重点页/片段，具体字段见[内容配置](../content-authoring.md)。阅读目标显示要求范围内已记录的不同页面数，练习显示正式提交通过的不同题目数，视频显示服务端确认的有效观看时长；不得使用当前页、客户端播放位置或运行公开样例次数冒充完成进度。重点标记在目录或片段列表中显示简短文字，可跳到对应位置，跳转本身不增加观看时间。配置与当前材料不符、保存失败或其他播放会话占用时，显示真实错误和重试入口。

### 练习与单元测验

练习固定单题模式，正文一次显示一道题，底部提供上一题/下一题；题目目录可随时跳题。每题使用“提交答案”，错误可修改后重新提交。各题草稿和反馈独立保留，不因跳题串答案。学习目标仍以服务端正式通过的不同题目数计进度。

单元测验支持“单题模式”和“试卷模式”，两者共用同一份答案：前者逐题翻页，后者按试卷顺序纵向铺开。侧边题目目录标记未作答、已作答、判定中、正确/错误，并定位单题或滚动到整卷对应题。目录上方提供“提交试卷”，未答完全部题时禁用；交卷前不提供单题正式提交。交卷后由服务端锁定本人整份答案，显示真实得分与逐题判定，输入禁用、代码以只读文本展示，不再出现编辑或再次交卷入口。

测验“已完成”指交卷后全部题目已有真实终态判定，是否全对和分数单独显示，错题不会让一次性测验卡住剧情。基础设施错误或送交状态不确定不当作答错，也不允许盲目重交。结果页保留到学生选择“完成测验”继续剧情；练习全部通过后也使用“完成练习”显式继续，避免最后一次提交马上关闭反馈。

成绩主文显示服务端百分制，例如“66 / 100 分”，答对题数作为次要信息保留；所有分数向下取整，不由前端四舍五入。判定未结束时显示真实等待或需处理状态，不能显示0分冒充已判定成绩。题目目录没有交卷操作时不渲染空操作容器；交卷区靠留白分组，不额外叠加分隔线。单行结果的图标与文字在卡片中垂直居中，只有实际详情存在时才增加下方内容。

正文不再显示提交UUID、“当前第几题·可重复练习”、“正式提交后记录成绩”、自动保存长说明及空答案提醒；保留必要的真实错误、保存冲突和判定状态。结果卡片用细边框和背景区分，不使用厚左侧条；正确、错误与等待统一用GameIcon的Lucide图标，不能用字符勾号或表情符号。结果图标和状态文字垂直居中，只有一行状态时不预留空段或下方间距。题目目录只在有实际交卷内容时输出顶部操作区，练习不保留空白占位；测验交卷区域与目录之间不额外添加分割线。

### 可调布局

内容与支持之间只提供可拖动的分隔区，允许调节左右宽度；不显示“间距”按钮、弹层或额外布局设置。支持区域默认占 28%，可在 22%–42% 之间调节，卡片间距统一为 22px。范围必须留出内容、角色标签、输入框和分页按钮的最小空间。分隔控件有 44px 操作区、可访问名称与可见焦点；左右方向键调节分栏，`Home` 或双击分隔区恢复默认宽度。

阅读和答题的支持侧卡可用分隔条拖到右缘或按 `End` 收起，也可使用侧卡顶部的“折叠侧边栏”图标按钮。任务日志、学习资料列表、地图、我的班级和设置的目录侧卡保持显示，不提供折叠或展开按钮。阅读与答题的学习支持侧卡折叠后主内容填满可用宽度，在“回到小镇”旁显示“展开侧边栏”，重新展开恢复原布局。隐藏侧卡保持组件和草稿，不接收焦点；折叠后焦点落到展开按钮，展开后回到侧卡操作。折叠是当前工作区临时状态，切换或关闭工作区恢复，不写学习记录。分栏宽度作为本机显示偏好保存，只影响当前界面，不改变活动配置、原始资料、学生进度或成绩。小尺寸空间继续复用内容与支持切换；隐藏区不抢焦点。200% 字号下优先保持目标、正文和操作完整可读，不通过缩小正文或裁掉输入区容纳双栏。

## 颜色与文字

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--game-forest` | `#284b43` | 深绿按钮、目录等主要承托面 |
| `--game-paper` | `#fbf5e9` | 正文纸面 |
| `--game-gold` | `#e6be76` | 标题图标、选中与强调 |
| `--game-line` | `#d7c7a9` | 纸面分隔与控件边线 |
| `--game-ink` | `#513b28` | 纸面正文 |

新增页面引用令牌，不再创建近似但不同的一套绿色、纸色或金色。任务日志可以保留当前任务状态色与参考色调；完成、进行中、锁定和错误还需要文字或图标说明，不能只依靠颜色区分。

正文、标签、帮助文字和按钮文字使用 `rem`，跟随现有 100%、125%、150%、200% 文字偏好。布局、按钮和行高必须容纳放大后的文字；课程与代码继续使用适合阅读的字体。资料题名、当前题目和页码属于必要内容，可以作为正文标题或信息显示，不算重复页面主标题。

## 页头与导航

页头左上显示一个金线图标和一个中文主标题：任务日志、小镇图书馆、小镇地图、我的班级、设置、资料阅读或练习。页面组件不重复输出相同的 `h2`；正文分区使用有意义的次级标题，不加分类眉题或诗句。

右上使用统一的深绿圆角“回到小镇”按钮，直接关闭整个工作区。有上一级工作区时，另显示次级“返回…”按钮；`Esc` 返回一级，没有上一级时才回到小镇。按钮上的快捷键提示必须与当前行为一致。

返回通过会话的工作区历史完成，不另外维护一套局部导航栈。打开资料后返回图书馆，应恢复当前用户、班级的章节、搜索、类型筛选和列表位置；阅读位置与练习草稿按原有隔离规则保存。切换班级先成功载入目标状态再提交，失败保留当前班级，不能为简化界面先清空学生状态。

## 组件与交互状态

| 控件或状态 | 规则 |
| --- | --- |
| 按钮 | 使用原生 `button`；主要动作使用深绿，次要动作使用浅纸面；采用平面背景及0–1px等宽边线，选中使用颜色和细边线，不加底部台阶、厚侧边或inset装饰阴影；图标按钮提供可访问名称 |
| 目录项 | 复用通用目录项样式；当前项有金色选中状态及可程序识别的当前状态，不只靠悬停 |
| 单选筛选 | 复用 `.game-segmented` 分段按钮组；当前按钮使用 `aria-pressed` 表达选中状态 |
| 表单 | 标签与控件关联，搜索、输入框、`select`、`textarea` 使用共享边线、圆角与焦点样式 |
| 开关与勾选 | checkbox/radio 保留原生语义和关联标签；开关复用 `.game-switch`，使用原生 `input[type="checkbox"][role="switch"]` 与 `.game-switch-track`，保留选中状态，不用普通 `div` 模拟 |
| 音量与范围选择 | 使用原生 range，提供名称与当前值；设置音量实际控制当前小镇音乐 |
| 加载与提交 | 清楚显示正在执行的动作，期间阻止同一动作重复提交；不要用无限动画代替结果 |
| 无内容 | 区分尚无资料、搜索无结果、尚未加入班级等情况，给出相应的简短说明或已有操作 |
| 错误与不可用 | 显示真实错误、缺失材料或权限限制；保留可用的返回或重试入口，不伪造加载成功 |
| 禁用 | 使用真实 `disabled` 状态；需要解释的限制在相邻文字中说明，不能只降低透明度 |
| 焦点 | 沿用共享 `:focus-visible`，键盘焦点清晰可见；不要去掉轮廓后不给替代样式 |

状态文案直接描述当前情况，例如“正在切换班级…”或“没有符合条件的资料”。不向学生显示内部版本、快照、请求代号或技术处理细节。学习进度使用服务端验证的任务和步骤；阅读参与、视频观看不称为知识掌握率或正式成绩。

图书馆以章节目录、搜索和课件/视频筛选组织已授权资料；班级以当前班级、教师姓名、本人当前学习进度为主，另提供切换与加入区域；设置以账户为首项，随后为界面、音乐、操作、关于，素材来源与许可放在关于。设置不承担跳转班级或资料的菜单职责。

## 任务日志目录

任务状态和任务类型统一放在左侧目录的同一筛选区域：状态使用分段按钮，类型使用简洁下拉框；不得再在工作区上方放一整行筛选或总统计。目录与详情卡片从工作区内容顶部开始，删除工具行后不保留占位留白。

“委托目录”使用清晰的1.45rem标题，不添加房屋插图。目录封面向右渐隐透出真实地图，祖先不能用不透明纸面遮住渐变；筛选与列表保留纸面保证可读性。没有符合条件的委托时，在剩余列表区域中央显示“没有委托”，不再显示0条统计、重复图标或长提示。

## 输入、焦点与偏好

打开工作区后，角色移动和世界快捷键暂停，输入框、代码编辑器和阅读控件接收其自身输入。不要把输入的 WASD 或方向键同时传给世界，也不要轮询 UI 状态触发世界移动。

工作区使用既有焦点管理：进入时焦点落到可用容器或控件，Tab 与 Shift+Tab 顺序合理，隐藏分区不接收焦点，返回或关闭后恢复到合理入口。地图保留当前焦点，不自动抢焦点，也不新增 WASD 或方向键选择目录；地图操作仍可通过鼠标与 Tab 到达，`Esc` 有历史时返回一级，无历史时回到小镇。只有当前工作区处理关闭，避免一次 `Esc` 同时返回并关闭多层。迟到请求不得在退出、换班或换账号后重新打开页面或覆盖新状态。

同一对白节点切换轮次时，打字动画从当前轮文本开始，清理上一轮计时器；减少动效时直接显示当前轮全文。末轮选项仍在全文显示后出现。

地图、对白和活动助教展示同一角色资料。地图使用角色指定精灵与朝向、按脚底对齐格子，未放置角色不生成地图对象；不再生成游走装饰居民。角色说话人的名字和立绘由服务端解析，私有立绘按当前班级授权加载，切班、退出和替换时释放资源。没有适用流程时显示明确交互反馈，不进入旧对白兜底。图书馆打开行为由流程动作决定。

减少动效偏好包含本机设置与系统偏好。状态与导航不能依赖动画完成才能使用，减少动效时仍显示必要反馈。字号、动效和音量是本机界面偏好，不写入学习成绩；音乐仍须遵守已有启用与退出会话行为。

## 开发工具

HUD 在设置后显示“开发工具”，由服务端返回的 `dev_tools_enabled` 控制。普通学生仅在 API 同时显式设置 `REBORN_ENV=development` 和 `REBORN_DEV_TOOLS=1` 时获得能力。教师工作台创建的体验学生获得本班体验存档的重玩能力，使用独立的体验重置接口。自动化验收使用隔离环境和新建账号。

开发工具沿用共享页头、深绿按钮与独立纸面卡片，明确显示当前账号和班级。“重新开始当前班级”先展开一次内联确认，再由“确认重新开始”发出请求。确认文案应说明当前班级的任务、阅读和练习成绩会被清除；助教仅断开客户端恢复指针，服务端会话、调用审计与预算记录保留。取消或关闭不发出重置请求。请求期间禁用重复操作，失败显示真实原因并保留重试和返回入口，不提前清空客户端状态。

成功后只清理当前学生、当前班级的进度及对应阅读、草稿、助教恢复和资料筛选缓存，重新显示欢迎流程，并从小镇出生点开始唯一主线。保留登录令牌、账号、班级成员关系、其他班级和其他账号的记录，以及本机字号、动效和音乐偏好。普通学习界面不提供该操作；该工具不新增快照、撤销系统或替他人重置的入口。

## 验收要求

本节是每次变更的检查要求，不表示这些检查已经通过。实际结果、环境和未覆盖范围写入 [验收记录](../acceptance.md)。当前交付以 1920×1080 桌面 Chromium 为准；已有自适应布局保留，但不据此声称手机、实体触屏、超宽屏或手柄通过验收。

- 各工作区使用同一页头，只有一个页面主标题；“回到小镇”、一级返回与 `Esc` 行为一致。
- 外壳无背景、边框、阴影，卡片独立且间隙可见小镇；目录、正文、状态色和控件样式一致。
- 100% 与 200% 字号下，长标题、搜索筛选、目录、页码、输入和主要动作可达，没有文字被固定高度裁掉或页面横向溢出。
- Tab 顺序、可见焦点、标签、按钮名称、选中与禁用状态正确；在输入与代码区键入不会移动角色。
- 加载、空结果、错误、禁用和重试显示真实状态，重复点击不会制造重复提交或切换。
- 资料返回位置、练习草稿、学生进度和成绩保持原语义；换班失败保留原状态，换账号后无旧数据或迟到请求污染。
- 打开页面、筛选、翻页、换班和导航不附带模型调用；世界保持同一个 Phaser.Game。
- PDF 在默认和调节后的分栏中完整适应左卡片，左侧无整体滚动条；底部分页、题名和原始页码可达，不向学生显示提取文本。
- 学习目标与角色助教的标签、立绘、消息与底部输入在 100% 和 200% 字号下可读；切换标签保留会话与草稿，拖动和键盘调节不会影响阅读进度或发出助教消息。
- 后台页面没有游戏令牌或控件样式泄漏，游戏页面没有后台主题或 Preflight 泄漏。
- 验证普通学生的开发工具双开关、确认、缓存和班级隔离。生产配置下普通学生不显示入口，普通开发重置接口返回 404。教师体验学生在独立接口下只可重置本人体验存档。
