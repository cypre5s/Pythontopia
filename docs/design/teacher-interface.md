# 后台界面规范

## 范围与入口

本规范用于 `/teacher` 的班级教学、课程资源和学习体验管理。后台以清楚的表格、表单和管理动作组织工作，与学生小镇中的纸面卡片界面分开。教师账号进入游戏工作区时使用 [游戏界面规范](game-interface.md)，不按账号角色混用主题。

后台复用 [`TeacherPage.vue`](../../frontend/src/features/TeacherPage.vue) 的管理布局、[`components/ui`](../../frontend/src/components/ui) 中已有的 Button、Card、Table、Dialog 组件，以及 [`AdminDialog.vue`](../../frontend/src/components/admin/AdminDialog.vue)。这些本地组件保留原许可证，不为一次页面调整引入第二套后台组件体系。

## 样式边界

[`teacherTheme.css`](../../frontend/src/features/teacherTheme.css) 只由教师路由加载。主题、工具类和原生表单样式限定在 `.teacher-page` / `.teacher-dialog`；弹窗渲染到门户时同样携带后台主题类。

后台不加载 Tailwind Preflight，不向全局 `body` 或学生页面注入无范围的控件重置。不在后台导入 `gameDesign.css` 或使用 `.game-workspace` 承托管理页，也不把后台主题从 `main.ts` 全局导入。

## 信息、控件与状态

页面保持明确的当前班级和管理分组，标题用于描述当前管理对象。列表使用现有搜索、筛选、分页和表格模式，新建、编辑和需要确认的管理动作复用已有弹窗。信息与操作围绕当前工作展开，不为填充页面增加没有实际用途的统计卡或装饰文案。

按钮、表单标签、表格标题、空结果、提交中、错误与禁用状态复用后台已有语义和组件。加载或提交期间阻止重复操作；接口失败保留用户可以修正的输入，不伪造保存成功。新增或修改数据继续使用服务端授权、校验和事务，界面隐藏入口不能代替权限控制。

弹窗标题与描述需要可访问，键盘焦点与关闭行为遵循现有 Dialog 组件。涉及未提交草稿、列表筛选和分页的页面延续原有状态保留方式，不借视觉调整清除草稿、重置教学数据或改变成绩含义。

## 验收要求

确认教师入口、表格、表单与弹窗仍使用后台主题；从后台进入小镇后，游戏布局和原生控件不受后台样式影响。检查常用列表、空结果、失败反馈、弹窗焦点及主要管理动作；权限和业务变更仍运行相应接口与回归验证。

本规范不声明本轮新增后台功能或已经完成后台实测。启动与检查命令见 [开发说明](../development.md)，实际通过、失败、跳过项记录在 [验收记录](../acceptance.md)。
