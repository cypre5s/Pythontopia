# 后台界面规范

## 范围与入口

教师后台位于`admin/`，使用React、TypeScript与shadcn/ui，以`/teacher/`独立入口提供班级、学生、课程内容、教学流程和课程包维护。学生`/world`继续使用Vue + Phaser及[游戏规范](game-interface.md)，不按账号角色混用主题。课程升级和旧实现退场遵守[阶段门槛](../content-authoring.md#分阶段实施计划与验收标准)。

界面围绕当前班级组织工作，顶部班级选择器和课程状态明确显示作用域。创建班级可导入课程包、创建空课程或稍后配置；无课程时提供真实空状态。班级导入独立内容，不能借编辑甲班影响乙班。后台导航覆盖概览、学生、章节、知识点、资料、题库、活动、流程与课程包，不机械复刻旧Vue包装组件。

## 样式与组件边界

后台使用项目维护的shadcn/ui基础组件、Tailwind和Lucide，保留其许可与来源；组件源码可按实际需求调整。优先直接组合基础按钮、表单、表格和弹窗，只为重复业务抽取组件，不层层包装。主题与重置样式仅加载在后台HTML，不进入游戏入口。两个应用通过正常页面导航切换，不嵌套React/Vue根节点，不共享状态容器。

后台单选下拉统一使用 shadcn/ui Select，视图切换使用 Tabs 的 `line` 样式。管理列表使用 shadcn/ui Table，统一表头与单元格留白。搜索与本表相关的筛选放在表格上方，行尾显示单条操作。支持批量操作的列表使用复选框，选中后显示数量及可执行动作。只读差异表和统计表提供筛选与相应的查看入口。

## 账号、表格与状态

教师与管理员使用学号登录，学生搜索与详情显示学号，保留前导零。账号菜单包含修改密码和退出，改密使用当前密码、新密码及确认，不另设导航页；服务端撤销旧会话。正常退出或账号失效清空用户状态，旧请求结果不能写回另一个账号/班级。

学生列表默认25人/页，可选10/50/100，支持学号或姓名搜索、状态筛选和排序。表头只选本页，跨页保留选择，全部筛选最多500人。改变搜索或筛选清空选择并回第一页。CSV/XLSX先预览再确认，保留可修正错误。重置和移出可通过单行菜单或批量工具栏执行，确认框显示单条学号或批量人数。移出只取消成员关系，保留账号和学业证据。章节、知识点、资料与题目的批量删除沿用逐条权限与引用检查，部分失败时保留未删除项并逐条给出原因。

顶部“进入小镇”打开新标签页，使用当前教师在本班的专属体验学生。首次进入创建账号，再次进入恢复同一存档。体验学生遵循本班章节开放规则，可以完成任务并保存结果，菜单内可以确认重玩。名册、班级统计和正式学生记录中不显示该体验账号。

所有页面必须有加载、空、失败、保存中和成功状态。接口失败保留草稿；课程修订冲突要求刷新/重新预览，不能伪报成功或静默覆盖。切班/切页前明确处理未保存修改，草稿和导入预览不得带入另一班。弹窗提供标题、标签、可见焦点、Tab边界和关闭后焦点恢复；请求期间防重复提交。

## 课程编辑

章节支持发布、暂停、时间和前置；知识点、资料和题目通过结构化关联组织。活动关联知识点先选所属章节，再勾选知识点，已选项跨章节保留并可直接移除。资料可未归类上传、替换、预览，转换中和失败明确显示，不分必读/补充。题库先独立编写，来源仅AI生成/导入，审核状态为草稿/可用/停用，参考依据可选；有序活动选题是唯一关系来源，私有答案和用例不进入学生视图。

教学流程的公共与章节流程、地图交互与开放规则、任务目标与依赖、助教教学角色共用左侧工具区与右侧工作区。四个标签均使用图标配合文字，分别对应流程、地图、任务清单与助教。当前选择、新建和设置位于工作区顶部。右键节点打开浮动属性卡，键盘可用 Shift+F10，选中的卡片也有可点击的属性按钮。关闭属性后仍可操作画布。地图页保留固定对象选择、区域绘制及开放规则，助教页用角色卡管理配置与使用范围。

流程和任务画布使用 React Flow。左侧工具可拖入画布或点击添加，新增节点保留可连接端口，由教师手动连线。拖动期间保持节点可见，松手后记录位置。公共及章节流程共用条件、对白、选项、随机路由、活动等待与返回、界面操作、建筑解锁和结束节点。打开页面只设置目标工作区，需要提示时在前面连接对白。

从左侧「触发入口」选择角色或地图交互点，再连到起始节点。流程选择先选公共流程或章节，再选具体流程。对白选择角色时保存稳定 ID，显示随角色改名更新；自定义说话人用于旁白。任务目标与导航角色必须已放置。地图编辑器用游戏 Tiled 底图，交互标记和区域按逻辑格定位。

「助教教学角色」统一新增、编辑和删除角色，维护名字、立绘、地图像素外观和人设，显示放置状态；新增默认未放置。系统素材可直接选择，自定义图片直接上传，无需填写来源与授权，可预览精灵的方向和行走。上传中禁止保存；失败保留已有引用，取消编辑不会替换已保存资料。人设明确提示本轮仅保存。课程开关、预算和默认答疑角色移至独立的“课程设置 → AI 助教”。

「地图交互与开放规则」的角色工具显示已放置与未放置角色，选中后点击地图放置、拖动移动，或输入坐标；配置朝向、出现条件及撤回放置。角色资料与地图位置共享同一草稿，不再有独立提交的新增角色弹窗。删除与撤回产生的引用阻断显示来源并可定位；改名、换图和人设编辑不重置学习进度。

未保存状态显示在保存按钮旁边。「取消编辑」经确认恢复本班上次保存的课程，包括四个标签中的修改和布局。服务端仍校验图引用、条件、可达位置及历史影响。按真实学生状态运行的流程预览是只读检查，体验学生入口独立保存自己的游玩进度。

「校验」列出问题、修复建议和可用的「定位」入口。定位会切到对应标签，并选中具体流程、入口、节点或配置项。涉及重置的改动显示独立警告，列出本班受影响的流程、任务和人数，保存时需再次明确确认。已完成的互动、尚在继续的互动与任务进度按各自影响范围处理。仅修改仍在使用的地图入口规则时，可先在小镇完成或点击「结束本次互动」。关闭网页或暂时离开会保留互动。

课程包页选择data/course下的解压目录，共用差异、学习影响与阻断项预览。ZIP上传关闭。等待时显示动态处理状态和真实等待秒数；导出完成后显示服务器目录路径。教师查看预览后确认导入，过期或课程变化须重做。对白节点按轮次显示独立输入框，支持添加与删除对白，沿用空行分轮的存储格式，分支可以连接各自附近的独立结束节点。全包包含私有答案，交换目录保持服务端私有。

## 验收要求

以1920×1080桌面Chromium为基准，验证登录/改密/退出、分页与批量范围、上传/替换/真实预览、活动复用、流程保存、按真实学生只读预览、课程包往返和跨班独立。验证键盘焦点、错误保留、并发冲突、同域深链刷新及后台/游戏样式隔离。只有对应业务真实验收完成后才移除旧Vue入口；实际结果和可选外部服务限制记录在[验收](../acceptance.md)，不以页面存在代替通过。

课程包列表采用可搜索表格，显示完整课程名称、创建日期、章节数、题目数和实际文件夹名，行尾提供预览导入。长名称和目录换行显示，取消列表外的底部分隔线。目录创建日期优先采用清单 exported_at，缺省使用 created_at，按后台时区展示。

角色配置使用基础信息、对话立绘、像素角色三个标签；素材使用带缩略图的限高滚动下拉，显示系统/此角色自定义标记与帧尺寸。课程设置页统一保存/取消开关、默认答疑角色与预算，使用课程修订控制并保护未保存草稿。活动答疑角色默认选择“使用课程默认角色”，也可指定本班角色；测验仍禁用助教。地图角色摆放时左侧列出角色与放置状态，右侧维护位置、朝向、条件。

## 编程题编辑

题库按题型筛选，编程题编辑标准输入输出样例、私有用例、初始 Python 代码与分步提示；提示每行一条。活动选题继续混排，助教继承课程默认角色或活动指定角色，不增加专用编程活动。

全站字体修订：正文与控件使用 -apple-system、BlinkMacSystemFont、Segoe UI、Noto Sans SC、sans-serif；标题使用加粗宋体回退链，代码仍使用等宽字体。后台沿用自身主题，内容面板和工具栏留白收紧。
