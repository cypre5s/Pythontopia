## 0. 这一步要回答的四个问题

| # | 问题 | 判读标准 |
| --- | --- | --- |
| 1 | CPU 上跑得动吗 | `page_short` 的 **RTF ≤ 1.0**（墙钟时间 / 音频时长） |

## 1. 拉模型（约 1.1 GB，不拉整个 9.3 GB）

```bash
cd ~/project/pythontopia            # 仓库目录
sudo mkdir -p /srv/pythontopia-tts/models && sudo chown "$USER" /srv/pythontopia-tts/models
command -v hf || pipx install huggingface_hub
WITH_OPTIONAL=1 DEST=/srv/pythontopia-tts/models bash deploy/tts/fetch-models.sh
```

预期：`backbone-ptq.gguf` ≈ 0.66 GB、`zac-keep2.gguf`、`spk-encoder.gguf`、`steer.gguf`、`gguf/voices/` 全部到位；脚本会自己拒绝过小的骨干文件。
失败处理：`hf download` 中断就重跑（幂等）；不要手工改文件名。

## 2. 构建镜像（只编译一次）

```bash
cd ~/project/pythontopia
docker build -f deploy/tts/Dockerfile -t pythontopia-reborn-tts:local \
  --build-arg JOBS=8 deploy/tts
```

要点与风险：

- 需要 Rust（文本规范化子模块）。镜像里用 rustup 装，构建阶段一次性。
- `JOBS=8` 是**故意不占满 48 核**：共享机上别人还在跑 milestone/ES，别把编译峰值压给别人。
- 编译约 5–15 分钟，磁盘临时占用 3–5 GB。
- **如果编译失败**（子模块、C++23、工具链版本）：先别硬啃，改走官方 release 预编译包（README 提到解压后自带 `start-zonos3.sh` / `zonos3-server` 二进制），把二进制 COPY 进 slim 镜像即可——这一步我未能核实发布包地址，需要你去 GitHub Releases 页面确认。

## 3. 基准测试

```bash
cd ~/project/pythontopia
REBORN_TTS_TOKEN=$(openssl rand -hex 24) bash deploy/tts/bench.sh
```

脚本做四件事：起一个 `--memory 4g --cpus 8` 的临时容器（端口只绑 `127.0.0.1:19191`）→ 等 `/v2/capabilities` → 合成两段中文并算 RTF → 采样 10 次 `docker stats` 取峰值内存 → 删除容器。

产物在 `.tmp/tts-bench/`：`capabilities.json`、`speakers.json`、`page_short.wav`、`page_long.wav`。

**把这两段 wav 下载下来听**（`scp -P 8122 master:.../page_short.wav .`）。听感不过关，后面所有工程都是白做。

## 5. 通过之后才做（不在 B0 范围）

1. `deploy/.env` 加 `REBORN_TTS_TOKEN`、`REBORN_TTS_MODELS_DIR`；
2. `docker compose -f deploy/compose.yml -f deploy/compose.tts.yml --profile tts up -d tts`（不发布端口）；
3. API 侧 `TtsProvider` 适配器 + `REBORN_TTS_*` 配置（详见 `2026-11-13-ZONOS3语音接入方案.md` §3）；
4. 后台"生成/重生成本页音频" → 审校 → 发布 → 学生播放；
5. 音频按 `sha256(文本|音色|模型)` 落私有存储，随课程包走。

## 6. 共享机的三条硬纪律（再强调）

- **不发布端口**：`tts` 只挂内部网络；基准测试才临时绑 `127.0.0.1`。
- **不 prune**：不动 `pythontopia/piston:release`、milvus、es 等任何别人的镜像/卷。
- **不超配额**：容器 `mem_limit: 4g`；如果 B0 发现峰值逼近 3 GB，先降 `--zac-threads` 或改用更小的分段，而不是放宽限制。
