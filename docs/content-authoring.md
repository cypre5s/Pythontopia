# 内容配置与发布

## 当前配置与 YAML 导入（2026-11-07）

章节任务、NPC对白和活动绑定位于 `backend/content/chapters/`。`shared.yaml` 保存公共NPC和第一章共用练习（quests为空），当前唯一内置主线为arrival，旧第二章任务不再导入，`chapter01.yaml` 保存当前第一章任务与剧情。题目答案只在后端 `backend/content/questions/concepts.private.yaml`，不得进入前端或公开响应。

每个稳定ID只对应一份当前配置，没有材料、活动、题目、任务或剧情的内容版本和快照。修改YAML后运行校验与seed，同ID直接更新，新ID新增；重复导入不增加重复记录。不再填写version、activity_version或material_version。schema_version只表示文件格式，story revision只处理并发推进，均不是内容版本。

```sh
cd backend
python -m app.chapter_content --check
python -m alembic upgrade head
python -m app.seed
```

seed会更新课程源章节、知识点、文本、例题、题目及YAML定义，但不会删除学生、班级、任务节点记录、阅读进度、提交或成绩；手动上传的当前文件不会被种子文本覆盖。内置共享任务按当前YAML集合收敛，移除的旧任务不会继续分配或展示；教师自有任务和历史学习记录保留。删除其他课程资源条目不会级联删除学生内容。保持ID稳定：旧节点被移除后历史记录仍保留，但不会自动映射到新节点；修改题面/答案不会重新评分历史提交，已有accepted仍按题目ID计入通过。若需要独立的新一次考核，应使用新的活动/题目ID。已完成任务不因配置更新自动撤销。修改必读页后，读取进度和检查任务证据都按当前必读页与保留的访问页重新判定。没有旧版教学内容可供恢复。

剧情会话仍持久化当前对白/等待活动及revision。导入后若原节点或活动绑定已失效，会话结束，下次交互重新选择入口；任务进度、阅读和成绩保留。不要在学生进行中随意重用节点ID表达完全不同的教学要求。

镜像构建时复制YAML，运行中的容器不直接读取宿主机文件；修改后需要重建API。当前容器每次启动依次执行Alembic、seed和API，因此启动会检查/同步当前配置，错误会阻止API启动。无需专门编辑器，使用文本编辑、校验与独立预览即可。

章节包包含 `schema_version/id/chapter_id/quest/story/activities`。`quest` 仍使用既有任务DAG；节点可配置 `navigation_target` 指向NPC。`story` 包含：

- `bindings`：命名活动绑定，每项明确 `activity_id/goal_id`。
- `entries`：每个NPC有从上到下匹配的入口列表，最后一项必须为 `when: {always: true}`。支持 `goal_complete`、`goal_ready`、`activity_started` 和 `always`；反复访问通过重新选入口实现。
- `nodes`：本轮支持 `dialogue`、`activity`、`end`。对白含稳定ID、说话者、文本、next或带ID的选项。`checkpoint` 只能引用交谈目标，并由服务端确认。单次演出无环，缺失跳转和不可达节点拒绝发布。
- `activity`：引用binding，必须定义 `returns.completed/suspended/unavailable`。打开活动保存等待点，玩家主动关闭后由服务端检查证据决定返回分支；刷新直接恢复等待活动。
- `checkpoint_effects`：本轮只允许明确的 `library_unlocked` 门禁效果；欢迎对白完整确认后提前开放图书馆。

新第一章依次为：镇长欢迎→馆员介绍→指定阅读→教练介绍→概念练习→镇长测试说明→独立章节测试→章节总结。镇长重复拜访只提醒；馆员记录中途离开与重返；练习和测试分别保存正式结果。章节测试不开放助教。

每个活动显式固定 `content.question_ids`。新增题目直接更新当前活动题集；同ID题目导入时更新题面和答案，历史提交不重评。

`ch1-lesson` 绑定当前资料186，馆员作为教学身份；完成规则为 `content.completion.required_page_ids: [10715,10723,10724]`，对应真实第34、42、43页。界面提供指定页导航并说明这只是阅读参与目标，掌握情况由练习和测试判定。服务器按用户、班级、活动保存页码和参与页集合；单条participation记录、访问末页或关闭窗口不能替代完成规则。完整文本资料仍可自由查阅。当前源PPT缺失，继续明确展示真实提取文本；已上传且转换ready的PPT/PDF仍使用既有私有阅读器。

本轮尚未实现可视化演出编辑器、任意循环、卡片节点或脚本化镜头节点；跨地图自动导航已衔接小镇与图书馆，地图渲染仍使用现有适配器。未来扩展应增加受限指令和验证，不允许在脚本中执行代码。YAML拒绝重复字段、锚点、别名、自定义对象及过深/过大的数据。

权威 HTTP 字段见 api-contract.md。真实课程种子位于 data/course-pack-43/json；保留原始文档、页面、章节和知识点 ID。种子可以重复运行，不创建默认教师或班级。39道原编程题统一保留为后端未发布档案，当前主线使用独立的第一章概念练习和章节测试。后续若要开放原题，应先审查题面、来源与私有用例，再绑定当前活动；归档导入本身不等于发布。

## 教师操作

地图配置位于 `data/world/world.json`，与章节文本分工：地图定义建筑、门和地点，章节脚本引用稳定的NPC/地点ID。maps中的建筑必须配置中文label、purpose、status、object_name及可达anchor；open建筑绑定portal，未开放室内使用closed/landmark并给出真实用途，不能虚构可进入场景。portal声明from、to、required_flags和blocked_message；源/目标都必须落在可达位置，并提供返回路线。建筑anchor不再复制进interactions。调整后运行 `node scripts/validate-world.mjs` 与 `node scripts/audit-assets.mjs`，再重建前后端。新增地图仍需使用现有支持的renderer或增加相应渲染实现。

当前11栋建筑都有屋顶名称及地图工作区目标，屋顶不附加开放状态文字；入口/出口使用小型素材箭头。地图工作区固定当前图，右侧卡顶部筛选建筑/人物，前往才触发实际导航；预览只画逻辑地图，外围景观只保留在实际场景与登录背景。未开放建筑不显示E提示或未开放弹字。图书馆门禁在新版镇长欢迎后开放，室内家具布局位于library.json。

同一物件可用`points: [{map_key, tile_x, tile_y}, ...]`替代单点字段，1至64个唯一真实位置，不能混用两种形式。每个位置都须在可走区，并与美术对象的interaction_id及脚底锚点一致。图书馆10组书架统一绑定library_shelf，地图只显示一个语义项；点击柜体优先去该柜前，普通导航选择最近可达柜前。物件证据半径2，不能用一个大范围点覆盖整个房间。旧任务事件保持原值，显示名称别名由前端兼容。

地图可声明walk_bounds（可行走矩形）、render_bounds（景观及有界镜头矩形）与camera_mode（centered/bounded）。小型室内使用centered，角色保持居中；大型室外扩展render_bounds但不扩展walk_bounds。静态素材和碰撞须保持一致，出生、NPC、交互与传送位置均须在行走范围内，保留旧存档坐标。新增素材保留原始PNG和来源记录，用图集帧或图层配置排布。

管理员通过 CLI 显式创建教师账号。教师登录后台，创建班级并分发加入码；学生注册后加入。教师上传文件，等待 ready 或查看 failed 原因，再创建自己的教学活动，绑定章节、NPC 和材料。共享种子不能被教师原地覆盖；新内容使用自有活动和任务。

任务使用 JSON 节点列表编辑。先校验再保存，按稳定ID关联。节点支持 TALK_TO_NPC、PLAY_DIALOGUE、REACH_LOCATION、INTERACT_OBJECT、STUDY_LESSON、COMPLETE_PRACTICE、PASS_ASSESSMENT、REPORT_BACK。dependencies 是节点 ID 列表，aggregation 默认 ALL，可用 ANY；optional 是可选目标。学习/练习节点必须绑定实际 activity_id。

分支父节点给出 choices（id、label），子节点用 condition: {node, choice} 引用直接父节点。任务完成只要求实际选择的支路；不得用任意代码或 SQL 作为条件。effects 只接受 set_world_flag。重复 ID、悬空依赖、环、错误内容、非法效果应在保存前被拒绝。

NPC 的教学身份由活动 npc_key 配置决定，不创建第二套页面或 Agent。对白是确定性脚本，不调用模型。新增 NPC/活动/任务通过配置 API 完成。世界坐标须经地图可达校验，图书馆室内边界为18×14。

教师按班级发布章节，指定 published/paused、带时区 opens_at与可选前置。界面默认 Asia/Shanghai，服务端按当前时间即时判定。暂停不删除成绩；当前策略为暂停后拒绝继续访问该章，重新开放后从已保存状态继续。教师预览不可写入学生成绩。

## 媒体与安全

文本使用 UTF-8；PDF 支持私有阅读；MP4/WebM 支持鉴权文件流与 Range；PPT/PPTX 必须经过配置的隔离 LibreOffice 转换。未安装转换环境时保留失败状态，不能伪报成功。不要将私有材料复制到 frontend/public，不要把隐藏答案写进题干、公开样例或助教可见上下文。同material_id上传替换当前文件，绑定该ID的活动读取新内容；旧文件不作为历史版本提供访问。

## 自有章节与知识点

教师后台“课程与知识点”可新增和编辑自有章节/KC；共享的原7章/65KC只有管理员可修改。新增内容仍属于Python语言基础单一课程，并非另建多课程平台。无引用的自有条目可删，有活动、任务、发布引用时返回409。

活动可多选同章的共享/自有KC。绑定直接更新活动并保留真实来源编码与页码；不能引用另一位教师的私有KC。新增题目直接加入当前活动题集，任务只引用活动ID。

任务日志按主/支线和进行中/已完成筛选。侧线不隐式阻挡主线的章节前置。教学、练习与其他工作区共享同一实现，新增绑定不复制页面。

排课界面时区由frontend的VITE_TIME_ZONE或容器构建参数REBORN_TIME_ZONE配置，默认Asia/Shanghai。所有API时间戳带明确偏移，数据库保存UTC；DST不存在或重复的本地时刻会被界面拒绝，避免静默错排。

后台操作入口（2026-11-05修订）：课程结构通过「章节 / 知识点」子标签查看，每个列表独立搜索、筛选与分页；新增、编辑、删除在弹窗中确认。材料与题库默认每页10条，上传材料/新增题目通过弹窗完成，关闭后保留未提交草稿。章节管理直接在目标章节行设置解锁日期并保存，或立即解锁；所有安排使用当前任务定义。已有前置条件会显示在章节标题下，不会静默移除。题目保存直接更新当前活动题集；排课仅控制开放状态、时间与前置条件。活动/NPC/任务编辑本轮不改。高级JSON格式错误时保留原内容并阻止创建；刷新/退出后不保证草稿保留。


## 课程包PDF与补充视频导入（2026-11-07）

专用CLI `python -m app.course_media <archive.tar.gz>` 接入用户提供的课程包43媒体，只更新当前Material和私有文件，不调用seed、不创建Activity/Quest，也不修改学生阅读、任务、提交或成绩。无需新增数据库迁移。

7份PDF原位绑定材料186..192，保留现有content.pages中的561个原页面ID、页码、标题和提取文本，类型改为pdf。当前第一章仍使用材料186及原全局页10715/10723/10724（第34/42/43页）；提取文本继续用于检索和引用，界面展示真实PDF并允许展开当前页文本。普通上传会重新生成页ID，不能替代此专用导入。

34份MP4按可信video_manifest.json的章节顺序映射到Chapter.order_index，按来源video_id复用当前材料记录，数据库分配新增材料ID；重复导入不会新增重复视频。视频标记supplementary=true，只作为补充资料，无学习完成要求、正式成绩或新主线。全部材料的library_available严格为true；共享源还需source.kind=course_media_pack/course_id=43。学生仍必须属于班级且对应章节已开放，暂停/未到开放时间或跨教师资料仍拒绝；普通上传未绑定材料不会因此自动公开。

导入器先完整检查路径/链接/重复成员、文件与总量、源清单、PDF页数和原页面ID、MP4文件签名及34份SHA256，再将文件写入私有存储并事务更新材料。可信清单来自后端镜像携带的仓库JSON，不能由包内清单任意替换。当前文件使用内容哈希存储键，同键对象校验一致时复用，不一致时拒绝覆盖；数据库失败回滚，未引用文件不会发布。该CLI用于管理员导入已核查课程包，不是公共的任意归档上传端点。

原包有43个文件，压缩884347179字节、解压文件总量919211590字节：7PDF、34MP4和两份清单/字幕JSON，无PPT/PPTX。PDF页数45、73、98、74、105、50、116，合计561。视频分章3/2/10/4/4/4/7，总标注时长32384秒（约9小时）。清单及字幕与仓库已有JSON一致；全部kcCodes为空，字幕为machine_generated_unreviewed。此次不会自动建立知识点级视频映射或把字幕接入助教，更不会用机器字幕当标准答案。

文本转PDF后，服务端活动阅读位置优先恢复；资料库已有PDF位置优先于旧文本位置，缺少PDF缓存时以原文本页索引映射真实页码。视频播放时间保存在本机并按用户、班级、材料隔离；补充视频的浏览、seek和续播不写入活动参与、任务或成绩，也不调用模型。实际部署、核对和浏览器结果见acceptance.md，容器导入命令见development.md。
