### 9.4.5.1 测试范围与环境

本模块功能测试聚焦学习闭环主链路：**进入关卡 → 看课件/视频完成 → 关卡练习提交 → 章末测试通过/不通过 → 星级计算 → 进度持久化 → 解锁下一关**，并覆盖关键防护点（OJ 完成 evidence 强校验、章测去答案下发与超时拒收、时长上报限频）。环境采用演示态全栈：前端 `http://localhost:5173`（容器态 `http://localhost:8080`）、后端 `:18080`、graph `:18091`、Postgres `:15432`、Redis `:16379`，课程包 `packId=43` 已 seed（7 文档 / 561 页 / 65 KC / 39 题），主线 seed 已写入 24 个 Stage 与 96 道客观题、39 道 OJ 编号。测试账号：学生 `stu_demo`（已加入绑定《Python 语言基础》的班级）。测试方法以**手工黑盒 + 接口验证**为主，结合后端单测（`StageCompletion` / `StarFormula` 纯函数）与前端 Vitest（`StageLearnPage.spec.ts` 等）。

### 9.4.5.4 小结

本模块设计功能测试用例 **10 条**（TC-M05-01 ~ 10），覆盖「进入关卡 / 看 / 学 / 练（客观题 + OJ evidence）/ 章测通过 / 章测不通过与超时 / 星级与补星 / 进度持久化 / 解锁下一关」全部主链路与关键防护点。演示环境执行结果：**通过 10 / 10，通过率 100%**，缺陷 **0** 条（无 DF-M05-NN）。其中 OJ evidence 强校验（TC-05）、章测去答案下发与超时拒收（TC-06/07）、时长上报限频（TC-02）为防作弊 / 防刷重点项，均按设计口径生效。遗留风险：客观题题库为「通识题」（非课件原题），章测预生成依赖 graph 服务可用性（不可用时 `prepare` 走重试 / `FAILED`，需重新准备），建议在比赛演示前预热各章题面至 `READY`。
