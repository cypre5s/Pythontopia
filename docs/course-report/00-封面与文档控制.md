## 编制说明（摘要）

Pythontopia 是一款面向高校 Python 初学者的**多端像素学习小镇「第二课堂」**。它针对大班统一进度下「翘课、跟不上、坚持不下去」的学生，提供一处课外可达、可按自己节奏「看→学→练→测」的补位学习场。系统以 Alethicode `packId=43`《Python 语言基础》课程包为唯一知识底座，把一门完整课程拆解为 65 个知识点（KC），通过对话式学习画像、课件 RAG 问答、多智能体资源工坊、训练场真题判题、Bug 矿洞调试与复盘大厅，把游戏化玩法严格映射到教育闭环上，做到「教育优先、游戏承载」。

本报告是该项目的课程设计成果文档，遵循「**格式参考实训报告骨架、内容全部来自仓库真实代码**」的原则编写：所有技术栈版本、数据库表、REST 端点、前端页面、智能体与迭代版本号均可在仓库 `backend/`、`frontend/`、`services/`、`deploy/`、`data/` 中找到实体，不编造课件页码、题号与第三方数据。全报告由 12 份框架文件、4 份数据库数据字典分片与 13×3 份功能模块分片拼接而成，正文目标约 8 万汉字，配以丰富的 Mermaid / Graphviz 图与完整数据字典。

本文件（filecode **FC**）作为报告首篇，提供封面、文档控制信息、修订历史、**全局目录**与**责任签名表**，是阅读全报告的导航入口。
