## 1. 适用边界（与 `AGENTS.md` 一致）

- 项目名：`Pythontopia`，独立仓库默认路径 `/home/cypress/Pythontopia`。
- 课程底座：仅使用 Alethicode `packId=43`，课程名 `Python语言基础`。
- 课程种子数据必须内置到 `/home/cypress/Pythontopia/data/course-pack-43/`。
- 初始化后必须验证：7 份文档、561 页、7 章、65 KC、46 示例、39 题。
- 前端：Vue 3 + Vite + TypeScript strict + Pinia + Vitest + Phaser 3。
- 后端：Java 21 + Spring Boot + Maven，REST + DTO + 校验 + 统一错误返回 + 测试。
- Python 服务：FastAPI + LangGraph，结构化输出，fail fast，单 worker。
- 不启用 ReAct 循环。
- 不做纯前端假数据冒充真实业务数据。
- 不复制星露谷官方素材，不复制未确认 license 的素材。
- 主线玩法是网页版像素小镇；Beta 以紧凑闭环为准，不做开放世界。
- 必须保留轻量班级架构（教师 / 学生 / 班级任务 / 班级看板）。

## 4. 通用工程债红线

每个阶段在合并前必须满足以下硬要求，未达成即视为该阶段未完成：

- 前端：`npm run typecheck` 通过，无新增业务层 `any`；Phaser 与第三方动态对象必须封装在 `frontend/src/game/adapters/`。
- 前端：所有 API 调用必须经 `frontend/src/api/` 下的 typed client，且 DTO 与后端契约一致。
- 后端：新增 API 必须有 DTO、Bean Validation、统一错误返回（参考 `ApiError`）、最少 1 个 Service + 1 个 Controller 测试。
- 后端：数据库迁移必须用 Flyway，文件名带说明，影响表与不可逆风险写入文件头注释。
- Python 服务：Agent 输出必须用 `pydantic` 模型，禁止纯自然语言；故障 fail fast，禁止静默降级为聊天。
- 资源生成必须落库 `resource_run`：`run_id`、`agent_name`、`input_summary`、`output_artifact`、`evidence_page_ids`、`safety_result`、`grounding_result`、`created_time`。
- 严禁前端伪造 KC、引用页、判题结果、班级聚合数据。

## 5. 借用 Alethicode 时的统一约定

- 借用仅限抽取必要能力，不直接 import 老前端。
- 抽取的后端代码必须迁移到 `com.pythontopia.*` 包，删除与 Pythontopia 无关的字段、外键、上游服务。
- 抽取的 Python 服务代码必须迁移到 `pythontopia_*` 模块，移除非 Pythontopia 路由。
- 在被抽取的源码顶部加注释：

```text
// 来源：/home/cypress/Alethicode/.../<原文件>
// 抽取目的：<本阶段目标>
// 修改要点：<相对原文件的差异>
```
