# 阶段 07 — 资源工坊与六类资源生成

## 1. 时间窗口与定位

- 建议日期：2026-06-02 ~ 2026-06-08（第 2 周末 ~ 第 3 周中，约 5 ~ 6 天，是 Beta 中工作量最重的阶段）。
- 角色：1 名 Python Agent 负责人 + 1 名后端 + 1 名前端。
- 定位：把"个性化学习资源"从概念变为产品。本阶段实现六类资源生成链路、`GroundingCriticAgent`、`SafetyAgent`、`ResourceDesignerAgent` 等 Agent 协同流程，是 Pythontopia 教育价值的核心展示阶段。

## 2. 本阶段目标

- 在 `pythontopia-graph` 实现六类资源生成 Agent，并通过 LangGraph 编排：
  - 讲义（`ResourceDesignerAgent`）。
  - 思维导图（`MindMapAgent`，输出 Mermaid 文本）。
  - 练习题（`PracticeAgent`，输出可被阶段 09 判题的题目，但不输出隐藏测试）。
  - 代码案例（`CodeLabAgent`，可在阶段 09 Pyodide 中跑通）。
  - 拓展阅读（`ResourceDesignerAgent` 复用 + 引用页）。
  - 动画脚本/短视频脚本（`StoryboardAgent`，输出结构化分镜，不渲染视频）。
- 所有资源必须经过：
  - `GroundingCriticAgent` 审查（参考 Alethicode `grounding_critic.py`、`hallucination_detector.py`、`token_grounding_verifier.py`）。
  - `SafetyAgent` 审查（PII、敏感内容、答案泄露等）。
- 所有资源生成必须落 `resource_run` + `learning_resource`，并带 `evidence_page_ids`。
- 资源生成入口由后端"资源工坊"控制，前端在小镇"资源工坊"建筑触发；学生可按 KC 选择"我要讲义/思维导图/..."。

## 5. 任务清单

### 5.1 资源 schema

- T07-01 Flyway 迁移 `V040__learning_resource.sql`：
  - 表 `learning_resource`：
    - `id`, `user_id`, `pack_id`, `kc_codes` TEXT[], `chapter_id`, `type`（`HANDOUT`/`MINDMAP`/`PRACTICE`/`CODE_LAB`/`READING`/`STORYBOARD`），`title`, `content_format`（`MARKDOWN`/`MERMAID`/`STRUCT_JSON`），`content` JSONB，`evidence_page_ids` BIGINT[], `summary`, `safety_status`, `grounding_status`, `created_at`, `created_by_run_id` BIGINT, `feedback_status`（`NONE`/`LIKED`/`DISLIKED`），`feedback_note`。
  - 索引 `(user_id, kc_codes, type)`、`(user_id, created_at)`。
- T07-02 Flyway 迁移 `V041__resource_run_extend.sql`：
  - `resource_run` 增加 `correlation_id`、`scenario` 枚举扩展（`RESOURCE_HANDOUT`/`RESOURCE_MINDMAP`/...）、`graph_trace` JSONB 字段（存节点执行路径）。

### 5.2 Agent schema 与节点

- T07-10 `pythontopia_graph/schemas/resource.py`：
  - `ResourceRequest{user_id, kc_codes, type, focus_hint?}`。
  - `ResourceDraft`：`title`、`content`（按类型不同结构）。
  - 对每种 type 单独定义 `pydantic` 子模型：
    - `HandoutContent{sections: list[Section{heading, paragraphs, code_snippets, page_refs}]}`。
    - `MindMapContent{mermaid: str, kc_map: dict[str, list[str]]}`，Mermaid 文本必须可被 Mermaid CLI 渲染。
    - `PracticeContent{problems: list[ProblemSpec{title, statement_md, hints, sample_io: list, kc_codes, difficulty}]}`，**禁止包含 hidden tests**。
    - `CodeLabContent{walkthroughs: list[Walkthrough{title, narrative, code, expected_output, common_mistakes: list}]}`。
    - `ReadingContent{items: list[ReadingItem{summary_md, page_refs, kc_codes}]}`。
    - `StoryboardContent{scenes: list[Scene{title, narration, visual_hint, kc_codes, duration_seconds}]}`，禁止生成真实视频。
- T07-11 节点 `pythontopia_graph/nodes/evidence_fetcher.py`：
  - 调用 RAG `POST /rag/query`，按 KC + query 取 chunk。
  - 输出 `EvidenceBundle{chunks: list[RagHit], no_evidence_found: bool}`；若 `no_evidence_found`，下游 Agent 必须降级标注"基于通识知识"，并 grounding 状态标 `NO_EVIDENCE`。
- T07-12 节点 `pythontopia_graph/nodes/grounding_critic.py`：
  - 检查输出引用的 `page_no`/`page_id` 是否都在 RAG 命中集合内。
  - 对未命中的引用直接报错，进入 retry 路径。
- T07-13 节点 `pythontopia_graph/nodes/hallucination_detector.py`：
  - 调用规则：内容中提到的 KC code 必须存在；提到的章节名必须存在；提到的例子代码必须可执行（练习题与 CodeLab 走 syntax check）。
- T07-14 节点 `pythontopia_graph/nodes/safety_critic.py`：
  - 检查 PII、暴力歧视性内容、答案泄露（如练习题直接给出 hidden test 或可复制答案）。
- T07-15 节点 `pythontopia_graph/nodes/output_persistor.py`：
  - 不直接写后端 DB；输出 `ResourceArtifact`，由后端持久化（保持服务边界清晰）。
- T07-16 LangGraph 主图 `pythontopia_graph/graph/resource_graph.py`：
  - 路径：`load_profile_kc → evidence_fetcher → agent_designer → grounding_critic → hallucination_detector → safety_critic → output_persistor`。
  - 任一 critic 失败：返回 retry（最多 1 次）；仍失败则 `status=FAILED` 并 fail fast。

### 5.3 单类 Agent

- T07-20 `pythontopia_graph/agents/resource_designer_agent.py`（讲义、拓展阅读共用）：

- T07-24 `storyboard_agent.py`：

### 5.4 后端资源工坊

- T07-30 `com.pythontopia.workshop`：

## 7. 验收标准

### 7.1 功能验收

- 学生在 KC `for-loop` 上请求"讲义"：
  - 5 秒~60 秒内返回 200，`learning_resource` 增加 1 行 `type=HANDOUT`。
  - 资源详情至少包含 1 段引用页（page_no 真实存在于 `course_page`）。
- 学生在 KC `list` 上请求"思维导图"：
  - Mermaid 文本能被前端 mermaid 渲染。
  - `kc_map` 中至少有 3 个相关 KC。
- 学生请求"练习题"：
  - 返回 1~3 道题；每题有 sample_io；返回数据中无 `hidden_test_cases`、无完整答案。
- 学生请求"代码案例"：
  - 代码可在 Python 3.11 中执行，`expected_output` 与实际运行一致（CI 用 `ast.parse`+ `subprocess.run` 验证）。
- 学生请求"拓展阅读"：
  - 至少 2 个 item，每个 item 含 evidence_page_ids。
- 学生请求"动画脚本"：
  - 输出 3~5 分镜，每个 ≤ 90 秒。

### 7.2 防幻觉验收

- 注入"虚构 KC code" → 资源生成失败 → `resource_run.grounding_result.failed=true`。
- 注入"无 evidence" → 资源生成成功但带 `grounding_status=NO_EVIDENCE` 标签，前端显式标注。
- 注入"safety 失败" → `resource_run.status=FAILED`，无 `learning_resource` 落库。
- 抽样 5 个资源人工核对引用页：≥ 90% 引用真实存在且段落相关。

### 7.3 工程验收

- 业务层 0 `any`；前端 mermaid 渲染失败时有错误状态。
- `mvn test`、`pytest -q`、`npm run test` 全部通过。
- `resource_run` 中 `graph_trace` 字段记录节点顺序、耗时；可用于回溯。
- 节流生效：超过 `maxResourcesPerHour=10` 时返回 429 + `ApiError.code=RESOURCE_THROTTLED`。

## 9. 风险与回滚

- 风险：LLM 长输出超时；缓解：`PracticeAgent`/`HandoutAgent` 设置最大 token；超时 retry 1 次后失败。
- 风险：Mermaid 复杂图渲染失败；缓解：节点强制 syntax check；前端兜底显示文本。
- 风险：练习题中暗藏答案；缓解：safety 节点关键词扫描 + 单元测试断言。
- 风险：节流过严影响演示；缓解：演示账号在 `application.yml` 中通过 `pythontopia.workshop.allowlist` 放宽（默认空）。
- 回滚：删除 `learning_resource` 行 + 对应 `resource_run` + 回滚 `kc_mastery_event`（`source=RESOURCE_READ`），可单 user 还原。

## 10. 不做事项

- 不生成真实视频/音频。
- 不生成 hidden tests 或完整答案。
- 不在练习题或代码案例中拼接来自外部网站的内容。
- 不允许学生通过前端绕过节流（节流必须在后端校验）。
- 不让资源生成节点缓存 LLM 结果到本地后再"伪造"成新 run（每个 run 必须真实调用）。
- 不为了节省 LLM 成本去掉 grounding/safety 节点。
