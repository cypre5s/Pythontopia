## 7. 验收标准

### 7.1 数据验收

- 数据库中执行以下 SQL，结果须完全一致：

```sql
SELECT 'pack' AS kind, COUNT(*) FROM course_pack WHERE id = 43
UNION ALL SELECT 'document', COUNT(*) FROM course_document WHERE pack_id = 43
UNION ALL SELECT 'page', COUNT(*) FROM course_page WHERE pack_id = 43
UNION ALL SELECT 'chapter', COUNT(*) FROM course_chapter WHERE pack_id = 43
UNION ALL SELECT 'kc', COUNT(*) FROM course_kc WHERE pack_id = 43
UNION ALL SELECT 'example', COUNT(*) FROM course_example WHERE pack_id = 43
UNION ALL SELECT 'problem', COUNT(*) FROM course_problem WHERE pack_id = 43;
```

期望返回：`pack=1`，`document=7`，`page=561`，`chapter=7`，`kc=65`，`example=46`，`problem=39`。

- `course_page.content_markdown` 至少 95% 行长度 > 50 字符，验证不是空页占位。
- `course_kc.prerequisite_codes` 数组中所有引用的 `kc_code` 必须能在 `course_kc.kc_code` 中找到，无悬空引用。

### 7.2 API 验收

- `GET /api/course/kcs?chapterId=<某章节>`：对每个章节 KC 数之和等于 65。

## 9. 风险与回滚

- 风险：导出脚本误读取其他 pack 的行，污染种子；缓解：所有 SELECT 强制 `WHERE pack_id = 43`，并在脚本末尾 assert 计数。
- 风险：Markdown 中含单引号导致 SQL 转义失败；缓解：`build_seed_sql.py` 使用参数化生成或安全的 `psycopg.sql` 模板。
- 风险：`course_problem.hidden_test_cases` 为隐藏测试，可能被泄露；缓解：后端 `ProblemDto` **禁止**包含 `hiddenTestCases` 字段，仅服务端判题路径可读。
- 风险：`pgvector` 未启用导致后续阶段需要补迁移；缓解：在 `V001` 中执行 `CREATE EXTENSION IF NOT EXISTS vector;`。
- 回滚：保留 JSON 种子作为唯一真值，重新执行 `V006` 即可重置课程数据；如需重置 schema，删除 `pythontopia` 数据库后再次 `mvn spring-boot:run` 触发 Flyway。
